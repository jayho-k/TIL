# CLAUDE.md — TIL Study Project

이 저장소는 jayho가 공부한 내용을 정리하는 TIL(Today I Learned) 노트 저장소입니다.
코드 프로젝트가 아니라 **학습 노트** 중심이므로, 협업 방식도 그에 맞게 설정합니다.

---

## 프로젝트 성격

- 공부한 개념을 Markdown으로 정리한 저장소
- 주제별 폴더로 분류 (AI / CS / Server / Web / PS)
- 노트에는 이미지(`*.assets/` 폴더), Jupyter 노트북(`.ipynb`), 코드 예제도 포함됨
- 새 노트는 기존 폴더 구조를 따름 (MAP.md 참고)

---

## 학습 워크플로우 (핵심 규칙)

공부는 **2단계**로 진행한다.

### 1단계 — `.claude/`에서 초안 작성

작업 유형에 따라 저장 위치가 다르다:

| 작업 유형 | 저장 위치 | 설명 |
|-----------|-----------|------|
| 학습 초안 / 정리 중인 노트 | `.claude/임시파일명.md` | 자유롭게 작성하는 작업 공간 |
| 조사 / 분석 자료 | `.claude/research/주제명/파일명.md` | 외부 자료 분석, critical review 등 |

예시:
```
.claude/
  draft_kafka_consumer.md          # 학습 초안
  research/
    Milvus/
      cdc_critical_analysis.md     # Milvus CDC 조사 자료
    Kafka/
      kafka_replication_review.md
```

### 2단계 — 본 저장소로 이관
초안이 완성되면 아래 기준으로 본 저장소에 합침:

| 상황 | 처리 방법 |
|------|-----------|
| 기존 파일과 같은 주제 | 기존 파일을 읽고, 적절한 위치에 내용을 **끼워넣기** |
| 새로운 주제 | `MAP.md`를 참고해 올바른 폴더에 **새 파일 생성** |
| 기존 파일을 대체할 수준 | 기존 파일과 **병합** |

> `research/` 폴더의 조사 자료는 이관 여부를 따로 판단한다.
> 참고 자료로만 쓸 것이면 `.claude/research/`에 유지해도 됨.

이관 후에는 `MAP.md`에 새 노트를 등록한다.

> **파일 삭제 규칙:**
> - `.claude/` 루트의 임시 초안 파일 (`draft_*.md` 등): 이관 후 삭제
> - `.claude/research/` 폴더의 조사 자료: **삭제하지 않고 유지** (원본 참고 자료로 보존)

## 나와 함께 공부하는 방법

### 새 개념 정리할 때
- 어떤 주제인지 말해주면 적절한 폴더 경로를 제안함
- `.claude/`에 초안을 먼저 작성하고, 완성되면 본 저장소로 이관

### 기존 노트 찾을 때
- `.claude/MAP.md`에 전체 노트 목록이 정리되어 있음
- 키워드로 찾고 싶으면 바로 검색해줌

### 개념 질문할 때
- 노트에 있는 내용을 기반으로 설명
- 노트가 없는 내용은 새로 정리해줄 수 있음

### 노트 보강할 때
- 기존 노트를 읽고 빠진 내용, 더 깊은 내용을 추가 제안

## 파일 규칙

```
폴더/
  01_주제명.md          # 번호 순서대로 시리즈
  개념명.md             # 독립 주제
  주제명.assets/        # 해당 노트의 이미지 폴더
```

- 노트 파일: `.md`
- 실습 코드: `code/` 서브폴더
- 이미지: `파일명.assets/` 폴더 (Typora 스타일)
- Jupyter 실습: `.ipynb`
