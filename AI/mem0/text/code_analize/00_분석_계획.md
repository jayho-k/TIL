## 소스 provenance 주의

이 로컬 소스 폴더에는 `.git` 메타데이터가 없다. 따라서 이전 문서에 적었던 `bddca5d1...`은 Mem0 upstream commit이 아니라 **바깥 TIL 저장소의 commit**이었으며, 모든 분석 문서에서 제거했다. 현재 확정할 수 있는 기준은 package version과 파일 hash다.

## 목표

Mem0가 대화를 durable fact memory로 바꾸고 나중에 recall하는 전체 흐름을 source code 기준으로 설명한다. 각 강점은 "무엇을 제공하는가"가 아니라 "어느 코드가 어떻게 구현하는가"까지 연결한다.

## 2026-07-18 코드 재검토 핵심 결과

1. 기존 `bddca5d1...` 표기는 Mem0 upstream commit이 아니어서 package version + 파일 hash 기준으로 교정했다.
2. V3 add의 개별 Qdrant fallback 실패가 history/entity/반환 결과에서 제거되지 않아 false-success ID가 생길 수 있다.
3. prompt의 `linked_memory_ids`와 `use_input_language` 기능은 현재 write path에 실제 반영되지 않는다.
4. Qdrant `list()`는 한 page만 읽어 `delete_all()`이 scope당 기본 100개까지만 삭제할 수 있다.
5. memory 삭제 뒤에도 SQLite history의 이전 text와 recent messages가 남는다.
6. 한 batch의 recent messages는 timestamp가 같아, 10개 초과 입력에서 진짜 마지막 10개와 순서를 보장하지 않는다.
7. hybrid score의 신호 분모는 query 전체에 적용되고, reranker는 hybrid `top_k` 뒤에 실행돼 recall을 복구하지 못한다.

이 항목들은 각각 02~08 문서의 workflow, 제약, PoC 기준에 반영했다.

## 분석 규칙

1. source code로 확인한 사실에는 파일·class·method를 기록하고, 행 번호는 보조 정보로만 사용한다.
2. 문서 설명과 실제 code가 다르면 둘을 분리해 기록한다.
3. 추론·우리 정책·Mem0 기본 동작을 혼동하지 않는다.
4. library mode 외 component는 비교 목적일 때만 언급한다.
5. 실행 검증이 필요한 항목은 추측하지 않고 PoC 항목으로 남긴다.
