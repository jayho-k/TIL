## 초록

정보기술은 사람이 정보와 상호작용하는 방식을 근본적으로 바꾸었다. 온라인에서 생성·공유·전파되는 방대한 양의 콘텐츠 때문에 관련 정보에 접근하기는 갈수록 어려워지고 있다. 지난 20년 동안 추천 시스템과 검색(통칭하여 정보 검색 시스템)은 이 과제를 해결하기 위해 크게 발전해 왔다. 최근 대규모 언어 모델(LLM)의 발전은 다양한 언어 관련 과제에서 인간의 수행을 능가하는 역량과 일반적 이해·추론·의사결정 능력을 보여 주었다.

이 논문은 추천 시스템과 검색 시스템을 개선할 때 대규모 언어 모델 에이전트가 지니는 변혁적 잠재력을 탐구한다. LLM 에이전트를 사용하는 동기와 역할을 논의하고, 기존 연구를 상세히 설명할 분류 체계를 수립한다. 또한 추천과 검색이 현재 마주한 과제를 해결할 때 LLM 에이전트가 지닌 커다란 잠재력을 부각하고 미래 연구 방향에 관한 통찰을 제시한다. 이 논문은 이 영역의 LLM 에이전트 연구를 체계적으로 검토하고 분류한 첫 연구로서, 이 고도화된 AI 기술을 정보 검색에 활용하는 새로운 관점을 제공한다. 기존 연구를 이해하는 데 도움이 되도록 저자들은 다음 링크에 LLM 에이전트 기반 추천·검색 논문을 정리해 두었다: <https://github.com/tsinghua-fib-lab/LLM-Agent-for-Recommendation-and-Search>.

## 1. 서론

정보기술은 특히 우리가 정보와 상호작용하는 방식에서 인간의 삶을 근본적으로 변화시켰다. 정보화 시대의 발전은 인터넷에서 방대한 콘텐츠의 생성·공유·전파를 낳았고, 그 결과 개인이 관련 정보에 접근하기는 점점 더 어려워졌다.

이러한 배경에서 지난 20년은 추천 시스템(RS) [44, 174]과 검색 시스템 [10, 125]을 비롯한 정보 시스템이 발전한 시기였다. 일반적으로 검색 시스템은 사용자의 질의어를 이용하여 방대한 정보에서 관련 콘텐츠를 수동적으로 찾아낸다. 반대로 추천 시스템은 수집된 사용자 행동 데이터나 프로필 정보를 바탕으로 사용자가 관심을 가질 만한 후보 목록을 능동적으로 만든다 [2, 71, 114]. 일부 연구자는 잠재적인 사용자 요구를 검색어로 모델링한다는 점에서 추천을 특수한 형태의 검색으로 본다 [155].

최근 LLM은 주목할 만한 성공을 거두었고, 범용 인공지능으로 나아가는 가장 유력한 경로 중 하나로 여겨진다 [1]. LLM은 언어 관련 과제뿐 아니라 일반적 이해, 추론, 의사결정에서도 인간과 유사하거나 그를 능가하는 능력을 보였다 [179]. 연구자들은 대형 모델의 텍스트 처리와 상식 추론 능력을 활용하여 여러 추천·검색 과제를 수행해 왔다 [3, 145, 191]. 또한 LLM의 한계를 넘기 위해 다양한 LLM 에이전트를 구축하고 있다 [151]. 구체적으로 LLM 에이전트는 LLM을 핵심으로 삼고 메모리 관리, 워크플로, 입출력 인터페이스, 외부 도구 호출, 대형·소형 모델 협업 등의 기능을 갖춘다. 이로써 지능 수준이 인간에 가까워지고 더 복잡한 과제를 처리할 수 있다 [95, 178, 185].

추천과 검색은 중요하면서도 기초적인 과제이므로, 연구자들은 그 안에서 LLM 에이전트가 지닌 높은 가치를 점점 더 인식하고 있다. 이 논문은 LLM 에이전트를 이용한 추천·검색 연구를 체계적이고 포괄적으로 검토하려는 첫 시도이다. 먼저 관련 배경지식을 소개하고, LLM 에이전트를 이용하는 동기와 이들이 추천·검색이 직면한 핵심 문제를 해결하는 방식을 논의한다. 다음으로 전체 추천 또는 검색 시스템에서 LLM 에이전트가 맡는 역할에 따라 최근의 진전을 분류하는 체계를 세운다. 이어서 이 연구들을 자세히 설명하고, LLM 에이전트를 어떻게 구성·사용하는지 분석한다. IR 분야에 LLM을 적용한 연구는 이미 여러 편 있었으나, LLM 자체에만 초점을 맞추거나 [8, 13, 43, 148] 특정 IR 응용 하나만 다뤘다 [98]. 이 조사는 IR 기능 전 범위에 걸친 LLM 에이전트의 적용에 집중한다는 점에서 뚜렷이 다르다.

이 논문의 기여는 다음과 같이 요약할 수 있다.

- 첫째, 새롭지만 빠르게 성장하는 연구 분야인 검색·추천 연구에서 LLM 에이전트 연구를 처음으로 검토하고 정리한다.
- 둘째, LLM 에이전트가 왜 필요한지, 그리고 추천과 검색을 어떻게 강화하는지라는 근본적 질문에 답하는 분류 체계를 구성한다.
- 마지막으로 미해결 과제와 중요한 미래 연구 방향을 폭넓게 논의하여, 이 영역의 후속 연구에 영감을 제공한다.

논문의 구성은 다음과 같다. 2절에서는 추천 시스템, 검색 시스템, LLM, LLM 에이전트의 배경지식을 소개한다. 3절에서는 LLM 에이전트가 추천과 검색에 왜 필요한지 분석한다. 4절에서는 일관되고 포괄적인 분류 체계를 먼저 수립한 뒤 기존 연구를 자세히 설명한다. 5절에서는 사이버 환경에서의 체화된 LLM 에이전트 발전을 폭넓게 논의하고, 차세대 추천·검색에 줄 수 있는 영감을 강조한다. 6절에서는 LLM 에이전트 기반 추천·검색의 현재 문제와 중요한 미래 방향을 체계적으로 분석한다. 마지막으로 7절에서 논문을 맺는다.

## 2. 배경

### 2.1 추천과 검색

추천과 검색은 정보 검색의 핵심 과제이며 수십 년 동안 폭넓게 연구되어 왔다. 적용 시나리오는 서로 다르지만, 상호작용 인터페이스, 사용자/질의 모델링, 아이템 모델링, 매칭·랭킹·재랭킹이라는 유사한 핵심 구성 요소를 공유한다. 이 절에서는 각 핵심 구성 요소의 배경과 개념을 소개한다.

#### 2.1.1 상호작용 인터페이스

스마트 기기와 모바일 인터넷의 빠른 발전으로 사용자는 추천 시스템과 검색 엔진을 쓰는 수많은 응용 프로그램에 노출되었다. 전통적인 추천 시스템과의 상호작용은 단순하다. 사용자는 대체로 추천 시스템이 제공하는 콘텐츠를 무의식적으로 탐색한다. 예를 들어 전자상거래 웹사이트나 동영상 공유 플랫폼에서 그렇다 [109]. 한편 사용자와 검색 엔진의 상호작용 인터페이스는 보통 사용자가 검색 엔진 웹사이트나 프로젝트 관리 소프트웨어 등에 키워드 질의를 제출하고, 검색 엔진이 한 번 결과를 반환하는 방식으로 구성된다 [7].

최근에는 대화형 추천 시스템과 검색 엔진이 주목받고 있다 [176]. 이 인터페이스에서 사용자는 자연어 채팅 인터페이스를 통해 상호작용하며, 이전 결과를 바탕으로 추가 정보나 피드백을 반복적으로 제공하여 여러 턴의 대화를 만든다. 이러한 대화형 인터페이스는 인간의 의사소통 방식에 더 가깝고, 더 정확하고 만족스러운 결과를 얻는다.

#### 2.1.2 사용자/질의 모델링

추천 시스템과 검색 엔진이 만족스러운 결과를 검색하려면 사용자의 의도를 이해해야 한다. 예를 들어 전자상거래 앱에서 사용자가 사려는 상품을 식별하거나, 키워드 질의를 바탕으로 관련 웹사이트를 판별해야 한다. 그러려면 사용자 특성과 입력 질의를 정밀하게 모델링해야 한다. 추천 시스템에서는 성별·나이·선호도 등의 사용자 프로필, 탐색·클릭·구매 이력 등을 활용한다 [84]. 검색 엔진에서는 텍스트 분할, 개체명 인식, 품사 태깅, 관계 추출 등을 수행한다 [23]. 멀티모달·대화형 검색 엔진 같은 고급 시스템은 이미지 인식, 다중 턴 대화 이해 및 그 밖의 알고리즘도 포함한다 [62, 134].

#### 2.1.3 아이템 모델링

사용자/질의 모델링 외에도 아이템 모델링은 효율적이고 폭넓은 검색에서 본질적인 역할을 한다. 아이템 정보를 모아 이후 사용할 표현, 예컨대 특징 벡터로 전처리한다. 추천 시스템에서 아이템 모델링은 아이템 설명, 속성, 이미지, 구매자 및 기타 관련 정보를 고려한다 [82, 84]. 전통적인 검색 엔진에서는 이 과정을 인덱싱(indexing)이라 부른다 [23]. 웹페이지 콘텐츠에서 중요한 키워드나 태그를 식별하여 미리 저장함으로써 검색을 빠르게 한다. 고급 검색 엔진은 특정 도메인에 특화된 보조 지식 베이스를 사용하기도 한다.

#### 2.1.4 매칭, 랭킹, 재랭킹

추천 시스템 또는 검색 엔진은 매우 큰 후보 아이템 집합(대개 수백만 개 이상)에서 사용자/질의에 따라 정확한 아이템을 효과적으로 검색하려고 보통 매칭, 랭킹, 재랭킹의 세 연속 단계를 둔다 [55].

- **매칭:** 매칭(또는 리콜) 단계 [22]는 수백만 후보 전체에서 관련 가능성이 있는 수백 개 아이템을 가져온다. 입력 아이템 집합이 매우 크므로 이 단계의 알고리즘은 대체로 거칠지만(예: 벡터 내적) 매우 효율적이다.
- **랭킹:** 랭킹 단계 [16]는 매칭 단계의 출력을 순위화하여 상위 열 개 아이템을 고른다. 아이템 집합이 더 작아진 이 단계에서는 정확도를 높이기 위해 심층 신경망 같은 더 복잡한 모델을 사용한다.
- **재랭킹:** 재랭킹 단계 [97]는 다양성, 공정성, 신선도, 비즈니스 목표 등 추가 요구 사항에 따라 최종 아이템 목록을 다시 조정한다.

이 단계들을 활용하여 추천 시스템과 검색 엔진은 정확하고 관련성 높은 결과를 보장한다.

### 2.2 대규모 언어 모델과 LLM 에이전트

#### 2.2.1 대규모 언어 모델

언어 모델은 자연어 처리(NLP)에서 핵심적 역할을 하며, 주로 문장의 확률을 평가하고 문법적으로 올바른 텍스트를 생성하는 데 쓰인다. 초기 언어 모델의 발전은 n-그램, 최대 엔트로피, 은닉 마르코프 모델 같은 통계·확률 이론에 의존했으나, 장거리 의존성을 다루는 능력은 이른바 ‘차원의 저주’ 때문에 제한되었다. 딥러닝 기술이 등장하면서 강력한 일반화 능력과 유연한 아키텍처 설계로 인해 신경망 언어 모델이 점차 주류가 되었다. 순환 신경망(RNN) [119], 장단기 기억 네트워크(LSTM) [47], 게이트 순환 유닛(GRU) [19] 같은 모델은 내부 메모리 유닛을 이용해 긴 시퀀스를 처리하는 어려움을 효과적으로 완화했다. 그 결과 시퀀스 안의 문맥 의존성을 더 잘 포착하고 언어 모델 성능을 크게 높였다.

Transformer 모델 [131]의 도입은 순환 구조를 자기 주의 메커니즘으로 대체하여 학습 속도와 병렬성을 높였고 NLP 분야를 혁신했다. 동시에 컴퓨터 비전의 사전학습·미세조정 패러다임에서 영감을 받아, 언어 모델은 대량의 비라벨 데이터를 사전학습에 활용한 뒤 과제별 미세조정을 수행하기 시작했다. 이로써 BERT [30] 같은 고성능 모델이 등장했다. 학습 데이터가 급격히 늘고 컴퓨팅 자원이 크게 성장하면서 LLM은 NLP에서 절대적 우위를 차지했다. 이 물결은 NLP가 단일 과제 최적화 중심에서 멀티모달 지각과 생성으로 전면 전환했음을 뜻할 뿐 아니라, 언어 모델이 생성·이해·변환에서 새로운 높이에 도달했음을 알린다.

최근 연구에서 GPT-4 [1], Claude [6] 등의 LLM은 텍스트 생성, 다국어 번역, 감성 분석처럼 여러 NLP 과제에서 좋은 성능을 낼 뿐 아니라, 수학 문제 풀이, 논리 추론, 전략 계획처럼 전통적으로 깊은 인지 능력이 필요하다고 여겨진 과제에서도 인상적인 성능을 보인다. 이러한 포괄적 성능은 인공지능 기술의 성숙을 보여 주며, 인공지능 일반화(AGI)에 더 가까운 방향으로 꾸준히 나아가고 있음을 뜻한다.

#### 2.2.2 LLM 에이전트

에이전트 개념은 인간 지능을 모방할 수 있는 소프트웨어 개체를 개발하려는 목적으로 1960년대에 출발했다. 1970~1980년대에는 전문가 시스템 [142]이 부상하며, 고정된 규칙과 지식 베이스에 기반하여 전문 문제를 해결하는 지능 프로그램의 능력을 보여 주었다. 이 시스템들은 강력했지만 정적인 지식과 경직된 논리에 제한되었다. 1980년대 후반 Michael Wooldridge 등을 비롯한 연구자들은 에이전트를 재정의하면서 자율성, 외부 사건에 대한 반응성, 환경 및 다른 에이전트와의 상호작용을 강조했다. Minsky는 저작물 [88]에서 에이전트 개념을 자세히 설명하며, 사회적 상호작용에 참여하고 지능적 행동을 보일 수 있는 개체로 묘사했다. 복잡한 시스템에서 비교적 단순한 다수의 구성 요소(즉 에이전트)가 서로 협업하여 복잡한 문제를 풀 수 있다는 Minsky의 생각은 이후 다중 에이전트 시스템(MAS) [34]과 분산 인공지능 [9] 연구의 토대가 되었다. 1990년대에는 인터넷과 분산 컴퓨팅이 보급되면서, 연구 초점이 개방적이고 동적인 환경에서 에이전트가 협력하는 문제로 옮겨갔다. 이는 에이전트에 지능적 전략과 상호작용 능력을 요구했고, 복잡한 지능 생태계의 설계를 촉진했다.

21세기 초, 특히 딥러닝의 부상으로 대표되는 기계학습의 돌파구는 미리 설정한 프로그래밍 규칙에만 의존하지 않고 대규모 데이터에서 자율적으로 학습할 수 있게 했다. 이는 에이전트 연구가 규칙 기반 방법에서 데이터 기반 접근으로 전환했음을 뜻한다. 심층 신경망은 이미지 인식, 음성 처리, 자연어 이해 영역에서 지능 에이전트의 역량을 크게 강화하여 AI 에이전트의 새 시대를 열었다. 최근 GPT 계열 [1, 94]과 그 밖의 주요 언어 모델은 NLP에서 큰 진전을 이뤘고, AI 에이전트의 성능을 크게 높이며 그 심오한 잠재력을 입증했다.

> **그림 1. 에이전트의 세 핵심 모듈 개략도.** 제어 모듈은 저장(메모리 유닛, 지식 데이터베이스)·의사결정(계획 유닛, 추론 유닛)을 포함한다. 지각 모듈은 수집과 처리를, 행동 모듈은 체화·도구상자·피드백을 포함하며, 이들이 LLM 에이전트와 사용자를 연결한다.

에이전트는 환경을 지각하고, 의사결정을 내리고, 행동을 취할 수 있는 자율 컴퓨팅 개체이다. 그림 1은 LLM 에이전트의 세 핵심 모듈을 보여 준다.

- **지각 모듈:** 지각 모듈은 에이전트의 ‘감각’에 해당하며, 에이전트가 의사결정에 필요한 정보를 제때 얻도록 보장한다. 전통적인 단일 채널 정보 처리 시스템과 달리 LLM 에이전트는 텍스트, 청각, 시각, 영상 데이터를 포함한 멀티모달 정보원을 매끄럽게 통합하는 뛰어난 능력을 보여 더 견고하고 포괄적인 지각 프레임워크를 구축한다 [113].
- **제어 모듈:** 제어 모듈은 대리 ‘뇌’의 역할을 하며, 수집한 정보를 분석하고 가능한 행동 계획을 평가하여 최선의 전략을 선택한다. LLM 에이전트에서 LLM은 제어 모듈의 핵심으로 작동하여 언어 문맥의 이해·생성 능력을 높이고 상황 적응성, 창의성, 장기 기억 기능을 강화한다.
- **행동 모듈:** 행동 모듈은 에이전트의 ‘팔다리’에 해당한다. 결정을 실행하여 환경 상태를 바꾸거나 특정 목표를 달성하게 한다. LLM 에이전트에서 이 모듈은 단순 실행에 한정되지 않는다. 언어 생성, 도구 사용, 구체적 행동 같은 복잡한 과제를 실현하는 더 깊은 기능을 부여받아 에이전트의 적용 범위와 영향력을 크게 넓힌다.

현재 LLM 에이전트는 많은 분야에서 등장하고 있다. 기초적인 사무성 업무뿐 아니라 깊은 이해와 창의적 사고가 필요한 복잡한 과제에도 참여할 수 있다. 예를 들어 게임 개발에서는 비플레이어 캐릭터(NPC)에 생생하고 자연스러운 언어 능력을 부여하여 더 몰입적인 게임 환경을 만들 수 있다 [56, 95]. 교육 분야에서는 교실 보조자로서 학생에게 개인화된 지도를 제공하고, 교사의 과제 채점을 도울 수 있다 [70]. 과학 연구 분야에서는 CellAgent 같은 LLM 에이전트가 특수 도메인 지식의 결합이 필요한 단일세포 RNA 시퀀싱 데이터 분석 같은 복잡한 과제를 수행할 수 있다 [152]. LLM 에이전트는 계속해서 인간 역량의 경계를 넓히고 있다. 기술이 성숙함에 따라 더 혁신적인 응용 시나리오가 지속해서 나타날 것이며, LLM 에이전트는 인류 문명을 더 지능적이고 지속가능한 방향으로 이끌 것이다.

## 3. LLM 에이전트를 추천과 검색에 사용할 수 있는 이유

앞 절에서 논의했듯, LLM 에이전트는 더 단순한 모델과 비교해 새로운 능력을 도입하며 게임 NPC, 교육, RNA 설계 등 다양한 응용을 가진다. 이 절에서는 이 새로운 능력이 IR 문제를 해결하는 데 LLM 에이전트에 뚜렷한 이점을 주는 이유를 보인다.

### 3.1 LLM 에이전트는 심층 사고와 과제 분해를 할 수 있다

정보 과부하 시대에는 사용자 질의가 복잡하고 다양하므로, 전통적인 정보 검색 시스템이 사용자의 진정한 요구를 정확히 파악하기 어렵다. 반면 LLM 에이전트는 고도화된 언어 이해 능력으로 사용자 질의를 철저히 분석하여 핵심 정보, 암묵적 의도, 문맥 관계를 식별할 수 있다. LLM 에이전트의 진전을 뒷받침하는 핵심 역량은 심층 사고와 확장된 정보 입력 두 가지다. 먼저 심층 사고는 에이전트가 주어진 문제를 더 깊이 분석하게 하며, 보통 사고 연쇄(CoT) 기술 [38, 144]로 달성한다. 다음으로 확장된 정보 입력을 사용하면 사용자 선호, 문맥 정보, 아이템 프로필 등 더 많은 내용을 기억할 수 있다. 이는 대개 수백만 토큰 입력을 지원하는 긴 컨텍스트 윈도 같은 기술로 가능해진다 [32, 63]. 이 역량들이 결합되면 에이전트는 복잡한 IR 과제를 여러 하위 과제로 분해하여 더 효과적으로 실행할 수 있다 [5, 66]. 예를 들어 사용자가 여행을 계획할 때 LLM 에이전트는 목적지 선택, 일정 계획, 항공편·호텔 예약, 예산 계산으로 과정을 나눈 뒤 최종적으로 완전한 보고서를 제시할 수 있다 [153]. 이는 전통적 IR 시스템에는 상당히 어려운 일이다.

### 3.2 LLM 에이전트는 환경과 상호작용하고 정보를 통합할 수 있다

정보 검색에서 LLM 에이전트의 또 다른 중요한 이점은 환경과 상호작용하고 결과를 통합하는 능력이다 [53, 187]. IR은 여러 데이터 소스와 복잡한 검색 시나리오를 수반하는 경우가 많아서, 전통적 검색 시스템은 서로 다른 출처에서 정보를 효과적으로 수집하기 어려울 수 있다. 행동 모듈을 지닌 LLM 에이전트는 다양한 도구를 사용하고, 웹페이지를 탐색하고, 모바일 앱을 조작하며, 필요한 정보를 찾기 위해 독립적으로 인터넷을 검색할 수도 있다 [102, 112]. 나아가 전통 IR 시스템처럼 가공하지 않은 원시 결과를 전달하는 대신, 수집한 콘텐츠를 필터링·요약하여 명확하고 간결한 보고서로 사용자에게 제시할 수 있다.

예를 들어 학술 문헌 검색을 할 때 LLM 에이전트는 여러 학술 데이터베이스와 상호작용하여 서로 다른 분야의 연구 성과를 얻을 수 있다. 이어 결과를 분석·통합하여 포괄적 문헌 검토를 제공한다. 또한 사용자와 상호작용하면서 사용자 피드백을 바탕으로 검색 전략을 계속 조정하여 검색 결과의 품질을 높일 수 있다.

### 3.3 LLM 에이전트는 정보 시스템에 피드백을 생성하는 사용자 시뮬레이터 역할을 할 수 있다

IR 시스템은 개선을 위해 실제 사용자 피드백에 의존하지만, 실제 사용자를 대상으로 실험하는 일은 비용이 많이 들고 사용자 경험에 부정적 영향을 줄 수 있다. LLM 에이전트의 여러 모듈은 인간의 지각, 기억, 행동을 시뮬레이션할 수 있게 하므로 실제 사용자를 대신해 피드백을 수집하는 데 적합하다. LLM 에이전트는 사용자가 제품을 사용할 때의 실제 반응을 시뮬레이션하고 잠재적인 개선점을 식별할 수 있다 [169]. 또한 사용자의 사고방식과 관심사가 어떻게 변화하는지 탐색해 연구자가 사용자 행동을 더 잘 이해하도록 도울 수 있다 [95, 127]. LLM 에이전트는 사용자 선호를 시뮬레이션하고 추천·검색 시스템과 상호작용할 수 있다. 이렇게 생성된 상호작용 데이터는 더 견고한 IR 모델을 학습하는 데 사용할 수 있다 [116, 177].

요약하면 LLM 에이전트는 추천·검색 과제에 매우 적합하게 만드는 여러 핵심 능력을 제공한다. 사고하고 계획하는 능력, 다양한 도구와 접속하는 능력, 사용자 행동을 시뮬레이션하는 능력은 새로운 시대의 IR 사용자 경험에서 상당한 차이를 만든다.

> **그림 2. 추천과 검색을 위한 LLM 에이전트의 기존 연구 개요.** 추천용 LLM 에이전트는 사용자 상호작용(사용자 행동 심층 분석, 대리 의사결정), 아이템 표현 최적화(동적 갱신), 시스템 통합(단일 에이전트 작업, 다중 에이전트 협업), 환경 시뮬레이션(사용자 행동 시뮬레이션, 피드백과 최적화, 다중 장면 응용)으로 구분된다. 검색용 LLM 에이전트는 과제 분해기(과제 분할, 지식 강화), 질의 재작성기(인간과 유사한 추론, 사용자 요청 정교화), 행동 실행기(외부 도구/API 사용), 결과 종합기(결과 필터링), 사용자 시뮬레이터(평가 효율 향상)로 구분된다.

## 4. 추천과 검색을 위한 LLM 에이전트의 최근 발전

최근 LLM 에이전트와 전통적인 추천·검색 알고리즘을 결합하는 연구에서 큰 진전이 이루어졌다. 이 절에서는 전체 영역과 분류 체계, 에이전트의 역할, 최근 주요 논문이라는 세 가지 주요 영역에서 이뤄진 기여와 혁신에 따라 이러한 발전을 포괄적으로 살펴본다. 그림 2는 추천과 검색을 위한 LLM 에이전트 기존 연구의 분류를 보여 준다.

> **그림 3. 추천 과제에서 LLM 에이전트 역할의 네 영역.** LLM 에이전트는 상호작용, 사용자·아이템, 매칭·랭킹·재랭킹, 결과와 연결된다. 환경을 실제 추천 시스템처럼 모사하고 피드백으로 알고리즘을 최적화하며, 추천 시스템의 의사결정 중심으로서 개인화 추천 전략을 수립한다.

### 4.1 추천을 위한 LLM 에이전트

#### 4.1.1 분류 체계 소개

추천과 검색 영역에 LLM 에이전트를 배치하면서 새로운 프레임워크와 방법이 등장했다. 저자들은 이 영역의 분류 체계를 다시 정의하여, 추천 시스템에서 LLM 에이전트의 핵심 영역을 사용자 상호작용, 표현 최적화, 시스템 통합, 환경 시뮬레이션으로 식별한다. 그림 3은 추천 과제에서 LLM 에이전트가 쓰이는 네 영역을 보여 주며, 각 영역은 다음과 같다.

- **사용자 상호작용:** LLM 에이전트가 사용자와 시스템 사이의 중개자로서 자연어 이해·생성을 통해 상호작용을 강화한다.
- **표현 최적화:** LLM 에이전트를 통해 사용자/아이템을 더 잘 이해하고 표현하여 추천 과정을 더 정밀하게 만든다.
- **시스템 통합:** LLM 에이전트가 추천 시스템의 두뇌로 작동하여, 시스템이 분석·의사결정을 내리고 더 효과적인 결과를 얻도록 돕는다.
- **환경 시뮬레이션:** LLM 에이전트를 사용자 시뮬레이터로 사용하여 추천 시스템용 시뮬레이션 시험 환경을 구축하고, 피드백을 최적화하여 지속적인 개선을 달성한다.

#### 4.1.2 사용자 상호작용

전통적 추천 시스템은 사용자 과거 행동 같은 정적 데이터로 선호를 모델링한다. 그러나 이 접근은 사용자 선호가 빠르게 바뀌는 상황, 신규 사용자·신규 상품이라는 콜드 스타트 문제, 틈새 상품 추천의 롱테일 효과에 대응하기 어렵다. 또한 전통적 추천 알고리즘의 대화 추천은 자연어 상호작용으로 사용자 의도를 동적으로 포착할 수 있지만, 복잡한 인간 언어를 효율적으로 이해하는 방법, 대화의 일관성과 목표 지향성을 유지하는 방법, 대화의 모호성을 처리하는 방법이라는 과제를 안고 있다. LLM 에이전트는 사용자가 자연어로 상호작용할 수 있게 하고, 사용자 선호·과거 행동·대화 문맥 등을 분석해 고도로 개인화된 추천을 제공한다. 또한 특정 요구에 맞춰 추천 결과를 더 최적화하려고 외부 도구를 유연하게 호출하여, 더 풍부하고 개인화된 상호작용 경험을 제공한다.

구체적으로 AutoConcierge [164]는 LLM으로 사용자 질문을 논리 술어로 변환하고, Answer Set Programming(ASP) 시스템으로 정보의 일관성을 검사하여 시스템 상태를 갱신한다. 필요하면 누락된 정보를 채울 질문도 자동 생성한다. 사용자 선호를 모두 얻은 뒤에는 지식 베이스에서 일치하는 식당을 검색하고, LLM으로 결과를 자연어 추천으로 바꾼다. 사용자가 마음을 바꾸거나 다른 제안을 요구하면 AutoConcierge는 전략을 동적으로 조정하고 재평가하여 새 추천을 제공한다. 이 과정은 사용자 요구에 효율적이고 정확하게 응답하도록 한다.

ToolRec [180]은 LLM을 대리 사용자로 사용해 사용자 선호와 현재 시나리오의 일치 정도를 평가하고, 실제 사용자 의사결정 과정을 모사한다. 이후 사용자 속성 지시에 따라 랭킹 도구·검색 도구 같은 외부 도구를 호출하여 아이템 풀의 서로 다른 부분을 탐색한다. RecAI [79]는 LLM 능력으로 추천 시스템을 강화하거나 혁신하는 실용적 툴킷이다. LLM 에이전트는 먼저 사용자 대화의 의도를 바탕으로 포괄적 실행 계획을 세우고, 도구를 호출하며, 각 도구의 출력을 추적한 뒤 최종적으로 사용자 응답을 생성한다.

FLOW [11]에서 추천 에이전트는 LLM을 메모리 모듈·추천 모듈과 결합해 초기 추천을 만들고, 사용자 피드백에 따라 추천 결과를 최적화한다. 사용자 에이전트는 사용자 행동을 시뮬레이션하고, 추천 에이전트와의 상호작용 이력을 분석해 잠재 관심사를 더 정확히 포착한다. 이 반복적 정제 과정은 추천 에이전트와 사용자 시뮬레이션 에이전트 모두의 인지 능력을 점진적으로 높여, 더 미묘한 추천 생성과 더 충실한 사용자 행동 모사를 가능하게 한다. RAH [123]는 추천 시스템·보조자·인간을 결합하고, LLM 에이전트로 지각·학습·행동·비평·성찰을 수행한다. 이 에이전트들은 학습-행동-비평 순환으로 협업하여 사용자 성격에 대한 이해를 계속 개선한다. 예를 들어 사용자가 상호작용하거나 피드백을 주면 학습 에이전트가 초기 성격 특성을 추출하고, 행동 에이전트가 이를 바탕으로 사용자 행동을 예측하며, 비평 에이전트가 예측 정확도를 평가한다. 예측이 부정확하면 비평 에이전트는 이유를 깊이 분석해 개선안을 제시하고, 학습 에이전트는 예측이 실제 사용자 행동과 일치할 때까지 성격 특성을 조정한다.

요약하면 LLM 에이전트는 더 정확하고 개인화된 추천 서비스를 제공할 뿐 아니라, 지속적 자기 최적화와 외부 자원 호출을 통해 더 풍부하고 효율적인 상호작용 경험을 제공한다. 이는 추천 시스템이 단순 정보 제공자에서 지능적 상호작용 파트너로 전환했음을 뜻하며, 사용자 경험과 서비스 품질을 크게 높인다.

#### 4.1.3 표현 최적화

전통적 추천 시스템 프레임워크에서 각 사용자와 아이템의 정보 기록은 기초 정보부터 세부 속성까지 서로 독립적이고 정적이며, 대부분의 데이터 갱신은 수작업에 의존한다. 그러나 사용자 관심은 동적으로 바뀌고, 서로 다른 사용자는 같은 아이템에도 큰 관심 차이를 보며, 같은 사용자도 시점에 따라 관심이 달라진다. 정적 데이터 기반의 전통적 표현 방법은 이런 개인화 요구와 시간에 따른 변화를 포착하기 어려워 정확하고 효과적인 추천 서비스를 제공하는 데 문제가 된다. LLM 에이전트는 깊은 의미 분석, 멀티모달 데이터 융합, 외부 세계 지식을 통해 상세한 표현을 생성하고, 문맥 변화와 사용자 피드백을 민감하게 감지하여 사용자·아이템 표현의 동적 학습과 갱신을 촉진한다.

AgentCF [173]는 사용자와 아이템을 모두 에이전트로 취급하며, 각각 잠재 채택자의 선호와 취향을 유지하는 메모리 모듈을 갖는다. 이 연구는 사용자 에이전트와 아이템 에이전트를 동시에 최적화하는 새 협력 학습 방법을 도입하고, 실제 세계 상호작용 기록 차이에 따라 에이전트가 메모리를 조정해 사용자 행동을 더 정확히 반영하도록 하는 협력 성찰 메커니즘을 설계한다. KGLA [48]는 지식 그래프의 경로 정보를 자연어 설명으로 바꿔 언어 에이전트의 사용자 선호 이해를 높이고, 시뮬레이션 단계에서 사용자와 아이템의 상호작용을 바탕으로 사용자 메모리를 동적으로 갱신한다. 동시에 지식 그래프의 브랜드·카테고리·상품 특성 정보를 사용하여 자세한 아이템 설명을 만들고, 사용자와 아이템 사이의 경로 관계를 분석해 아이템 특성을 더 정확히 묘사함으로써 추천의 개인화와 정확도를 높인다.

Rec4Agentverse [170]에서는 아이템을 상호작용적·지능적·능동적인 LLM 에이전트로 변환한다. 이 에이전트는 여러 차례 대화를 통해 사용자 선호를 동적으로 획득하고 자신의 특성을 계속 갱신한다. 전통적인 정적 아이템과 달리 LLM 에이전트는 다차원 지식 표현을 제공하고 다른 에이전트와 협업하여 서비스 내용을 강화할 수 있다. 예를 들어 여행 에이전트는 사용자 관심을 바탕으로 일정만 추천하는 데 그치지 않고, 다른 에이전트와 협력하여 더 포괄적인 서비스를 제공할 수 있다. 또한 에이전트 아이템은 사용자 선호를 정확히 모델링하여 개인화 추천의 정확도와 사용자 경험을 높인다.

이 연구들은 개별 에이전트의 자율성과 에이전트 간 협업을 활용하여 사용자·아이템 표현을 효과적으로 풍부하게 만들고, 이들에게 더 큰 주도성을 부여한다. 그 결과 추천 알고리즘은 더 상황 의존적이고 동적으로 변하며, 사용자 선호의 미세한 변화와 상품 속성의 잠재 가치를 포착할 수 있다. 이 영역은 여전히 초기 단계라 관련 연구가 적으며, 앞으로 더 뛰어난 결과가 나올 것으로 예상된다.

#### 4.1.4 시스템 통합

+전통적 추천 시스템은 모델과 추천 결과를 정기적으로 갱신하는 배치 처리 아키텍처를 주로 사용한다. 예를 들어 최신 사용자 선호를 반영하려고 모델을 매일 또는 매주 재학습할 수 있다. 시스템 통합 중에는 데이터 정제, 특징 공학, 모델 선택 등을 별도로 고려해야 한다. 이에 비해 LLM 에이전트는 실시간으로 추천 전략을 학습·동적 조정하고 즉시 피드백 메커니즘을 지원해 수작업 개입 필요를 크게 줄인다. 이는 추천 시스템 효율을 높일 뿐 아니라 사용자 경험도 개선한다. 또한 LLM 에이전트는 각 에이전트가 서로 다른 데이터 소스나 과제에 집중할 수 있는 팀 협업 프레임워크를 지원한다. 에이전트 간 다층적·다차원적 협업과 정보 공유로 시스템은 사용자 선호를 더 포괄적으로 이해하고 고도로 개인화되고 문맥 관련적인 추천 콘텐츠를 제공할 수 있다. 프레임워크 구조 관점에서 이 연구들은 단일 에이전트 작업 [60, 64, 121, 139]과 다중 에이전트 협업 [37, 90, 141]으로 나눌 수 있다.

단일 에이전트 작업에서 RecMind [139]는 LLM 에이전트용 자기 영감 알고리즘을 도입한다. 이는 추천 시스템이 모든 과거 경로의 상태를 유지하고 그 이력 정보로 계획 결정을 최적화하도록 설계되었으며, 새 과제를 수행하는 능력의 일반화와 외부 지식의 효과적 활용에서 기존 추천 시스템이 갖는 한계를 해결하려 한다. InteRecAgent [60]는 LLM을 핵심으로 하여 지시 이해, 상식 추론, 인간-컴퓨터 상호작용을 처리하고, 추천 모델은 도메인 지식과 사용자 행동 패턴을 위한 도구로 둔다. 메모리 구성 요소와 동적 예시로 과제 계획·성찰 메커니즘을 강화하여, ID 기반 행렬 분해 같은 전통 추천 시스템을 자연어 상호작용을 지원하는 시스템으로 발전시킨다. CORE [64]는 오프라인 학습·온라인 확인 모델을 채택한다. 추천 시스템 모델이 오프라인 관련성 점수 추정기로 작동하고, LLM 대화 에이전트가 온라인에서 이 점수를 점검하여 확인되지 않은 관련성 점수의 합을 최소화함으로써 불확실성을 줄인다. BiLLP [121]의 LLM 에이전트는 고수준 계획자로 설계되어 학습 과정을 거시 학습과 미시 학습의 두 수준으로 나눈다. 거시 학습은 고수준의 지침 원칙을 획득하고, 미시 학습은 개인화 추천 전략 학습에 집중한다. 이 이중 수준 접근은 추천 시스템에서 장기 추천 전략을 달성하려 한다.

다중 에이전트 작업에서 MACRS [37]는 대화 흐름을 제어하고, 여러 LLM 에이전트로 응답을 생성하며, 사용자 피드백으로 대화 전략을 정제하고, 오류를 방지하며, 암묵적 사용자 의미를 해석하는 다중 에이전트 대화형 추천 시스템이다. MACRec [141]은 다양한 추천 과제를 협력하여 해결하기 위해 관리자, 분석가, 성찰자, 검색자, 과제 해석자 같은 전문 에이전트를 포함하는 다중 에이전트 프레임워크다. PMS [129]는 세 에이전트로 구성된다. 첫 번째는 주어진 질문에 답하기 적합한 상품을 추천하고, 두 번째는 추천 상품에 속하는 이미지를 바탕으로 후속 질문을 하며, 세 번째는 자율 검색을 수행한다. 이 시스템은 실시간 데이터 추출, 사용자 선호 기반 추천, 적응적 학습도 제공한다. Hybrid-MACRS [90]는 중앙 에이전트와 검색 에이전트로 이루어진다. LLM이 구동하는 중앙 에이전트는 사용자 상호작용, 선호 식별, 검색 질의 생성, 추천 생성 등을 담당한다. 검색 에이전트는 검색 엔진과 상대 검색 모듈로 구성되며, 중앙 에이전트가 만든 검색 질의를 처리하고 일치 상품 목록을 반환하며, 사용자 과거 행동 기반 개인화 정렬로 검색 결과를 최적화한다.

이 연구들은 자연어 이해, 개인화 선호 모델링, 문맥 인지 적응 의사결정 등 여러 차원에서 LLM 에이전트의 고도화된 능력을 활용하여 전통적 추천 시스템의 고유한 제약을 넘어서려는 시도이다.

#### 4.1.5 환경 시뮬레이션

과거에는 추천 알고리즘을 최적화하기 위한 사용자 피드백 수집이 시간과 자원을 많이 쓰는 과정이었다. 그러나 기술 발전과 함께 사용자 행동·선호를 모사하고 실시간 응답과 대규모 동시 테스트를 지원할 수 있는 고급 시뮬레이터로 LLM 에이전트가 등장했다. LLM 에이전트가 제공하는 높은 충실도의 환경을 활용하면 개발 팀은 추천 알고리즘을 더 효율적으로 시험·최적화할 수 있다. 이 시뮬레이션은 테스트 주기를 크게 단축할 뿐 아니라 사용자 프라이버시와 데이터 보안을 보장하면서 실제 사용자 데이터 의존도를 낮춘다. 연구 대부분 [135, 137, 160, 167, 188, 189]은 대화형 추천 시나리오에서 에이전트로 사용자 행동을 시뮬레이션하고 그 효과를 평가하는 데 초점을 둔다. 그 밖에 일부 연구 [21, 91, 177]는 더 실제적인 응용에서 LLM 에이전트가 가져올 수 있는 새 과제와 위험을 깊이 탐색했다.

iEvaLM [137]은 LLM 기반 사용자 시뮬레이터를 포함하여 다양한 시스템-사용자 상호작용 시나리오를 포괄적으로 모델링하는 혁신적 상호작용 평가 프레임워크다. 공개된 두 대화형 추천 시스템(CRS) 데이터셋에서 수행한 광범위한 실험 평가는 iEvaLM이 기존 평가 방법보다 상당한 성능 향상을 달성함을 보였다. 특히 추천 설명 가능성 평가를 포함해, 전통적 평가 패러다임에서 자주 간과된 핵심 측면을 다룬다. Agent4Rec [167]은 MovieLens-1M 데이터셋에서 초기화하여 서로 다른 사회적 특성과 선호를 지닌 LLM 지원 에이전트 1,000개를 생성한다. 이 에이전트들은 페이지 단위로 추천 시스템과 상호작용하며 시청, 평점 부여, 평가, 종료, 인터뷰 등을 수행한다. 실험 결과 생성 에이전트는 사용자 선호와 일치하는 아이템을 효과적으로 식별·반응하며, 에이전트 피드백은 추천 전략의 반복 학습·개선을 위한 강화 데이터로 사용될 수 있다. 따라서 추천 알고리즘의 포괄적 평가를 위한 이중 경로 접근을 형성한다.

Yoon et al. [160]은 CRS에서 LLM과 인간 사용자 사이의 행동 정렬을 정량 평가하는 새 프레임워크를 제시했다. 이 프로토콜은 (1) 논의할 아이템 선택, (2) 이진 선호 표현, (3) 개방형 선호 진술, (4) 추천 요청, (5) 피드백 제공이라는 다섯 평가 과제를 포함한다. 체계적 실험을 통해 LLM 생성 응답과 인간 상호작용 사이의 유의미한 행동 차이를 식별했을 뿐 아니라, 최적화된 모델 선택 기준과 고급 프롬프팅 기법으로 이 편차를 완화하는 실증적 통찰도 제시했다. Zhu et al. [188]은 현 LLM 기반 사용자 시뮬레이션 접근의 내재적 한계, 특히 의도치 않은 데이터 유출 문제를 분석했다. 이를 해결하려고 통제된 정보 공개 메커니즘을 구현하는 SimpleUserSim을 제안했다. 이 시뮬레이터는 목표 아이템 제목에 대한 접근을 제한하고, 추천이 성공적으로 완료될 때까지 아이템 속성 정보만으로 작동하면서 대화 주제를 목표 아이템으로 유도하는 직접 대화 전략을 쓴다.

RecAgent [135]는 LLM 에이전트 시뮬레이션 사용자를 상세히 정의한다. 고유 성격을 보장하는 프로필 모듈, 과거 행동을 기억하고 환경에서 동적으로 진화하는 메모리 모듈, 추천 시스템 관련 검색·탐색·클릭·페이지 넘김과 일부 사회적 행동을 포함하는 행동 모듈을 갖춰 실제 인간 행동을 효과적으로 모사한다. CSHI [189]는 제어 메커니즘을 도입하고 시뮬레이션 확장성을 높이며 인간-컴퓨터 협업 요소를 포함한다. 이로써 에이전트는 실시간 문맥과 과거 데이터를 바탕으로 행동을 유연하게 조정하고, 대화형 추천 시스템에서 더 정확한 개인화 경험을 제공한다.

LLM 에이전트는 대화형 추천에서 사용자 시뮬레이터로 작동하는 것을 넘어 강화학습과 추천 시스템 공격에서도 적용 영역을 넓혔다. SUBER [21]는 LLM 에이전트로 인간 행동을 모사하여 강화학습 기반 추천 시스템의 학습·평가용 합성 환경을 구성한다. 이는 부족한 온라인 데이터로 인한 높은 학습 비용을 완화하고, 실제 사용자 경험에 직접 영향을 주지 않으면서 모델 성능을 정확히 측정하기 어려운 추천 시스템 평가 문제를 해결한다. Zhang et al. [177]은 높은 계산 비용, ‘환각’ 취약성, 복잡한 사용자-시스템 상호작용 역학을 완전히 포착하지 못하는 문제 등 SUBER·Agent4Rec 같은 사용자 시뮬레이터의 단점을 다룬다. 사용자 선호를 명시적으로 모델링하고 논리 추론과 통계 학습의 장점을 결합하며 효과적 평가 프레임워크를 설계해 시뮬레이터의 신뢰성과 효율을 높인다. CheatAgent [91]는 먼저 추천 결과에 가장 큰 영향을 미치는 텍스트 부분을 분석한다. 이후 추천 시스템을 오도할 적대적 교란을 LLM 에이전트로 생성하고 프롬프트 튜닝으로 공격 전략을 최적화한다. 마지막으로 대상 시스템의 피드백으로 LLM의 공격 전략을 미세조정해 공격 효과를 높인다.

요약하면 이 연구들은 단순 대화 상호작용부터 복잡한 강화학습 환경까지 포괄하며, 사용자 행동 시뮬레이션에서 LLM 에이전트가 적용되는 지형이 진전하고 있음을 함께 보여 준다.

> **그림 4. 검색 과제에서 LLM 에이전트 역할의 다섯 영역.** 상호작용, 결과, 질의·인덱스, 매칭·랭킹·재랭킹을 LLM 에이전트가 연결한다.

### 4.2 검색을 위한 LLM 에이전트

#### 4.2.1 분류 체계 소개

일반적으로 사용자와 검색 엔진 사이의 상호작용은 사용자 의도, 질의 작성, 검색 실행, 결과 이해의 네 핵심 단계로 나눌 수 있다 [145]. 그림 4는 검색 과제에서 LLM 에이전트를 사용하는 다섯 영역을 보여 주며, 앞서 언급한 전형적 IR 상호작용 과정에 대응한다.

- **과제 분해기:** LLM 에이전트는 복잡한 과제를 더 작고 관리 가능한 구성 요소로 나누어 사용자 의도에 맞추고 전체 과제 실행을 강화한다. 이때 LLM 에이전트는 검색 엔진의 선행 인터페이스가 된다.
- **질의 재작성기:** LLM 에이전트는 사용자 질의를 더 명확하고 구체적으로 다듬어 더 정확한 검색 결과를 이끈다. 이때 LLM 에이전트는 질의 모델링 모듈이 된다.
- **행동 실행기:** LLM 에이전트는 사용자를 대신해 여러 도구·API와 상호작용하여 필요한 정보를 모은다. 이때 LLM 에이전트는 매칭·랭킹 모듈이 된다.
- **결과 종합기:** LLM 에이전트는 대량의 검색 결과를 요약하고 사용자가 의사결정에 필요한 핵심 세부 사항을 빠르게 파악하도록 돕는다. 이때 LLM 에이전트는 전통적 검색 과정에 새 능력을 더한다.
- **사용자 시뮬레이터:** LLM은 검색 시스템 개선 또는 평가를 위해 사용자 행동과 상호작용을 모사하는 사용자 시뮬레이터가 될 수 있다. 이때 LLM 에이전트는 검색 엔진에 피드백을 준다.

저자들은 위 영역 설명에 따라 검색 과제 관련 연구를 분류하고, 표 2에 다섯 영역의 대표 연구를 제시한다.

#### 4.2.2 과제 분해기

기존 검색 기술은 대체로 충분한 숙고 없이 사용자 질의와 문서의 관련성을 학습하는 데 초점을 둔다. 이 한계는 복잡한 검색 과제에서 치명적이다. 예를 들어 사용자가 ‘휴가로 어디에 갈까?’를 검색하면, 여러 여행지 비교, 여행 일정 세부 사항, 호텔·항공편 가격을 기대할 수 있다. 3절에서 논의했듯 LLM 에이전트는 강한 추론·과제 분해 능력을 지녀 정보를 단계적으로 수집·집계하고 사용자에게 포괄적 결과를 제공할 수 있다.

Laser [85]는 웹 탐색 과제를 **상태 공간 탐색**으로 보는 방법을 도입한다. LLM 에이전트는 낯선 시나리오와 유연한 되돌아가기를 다루기 위해 **과제를 미리 정의된 상태 집합으로 분해**한다. Deng et al. [29]은 사용자와 환경 모두와 **복잡한 다중 턴 상호작용을 요구하는 대화형 웹 탐색이라는 새 과제를 제안**한다. **과제가 복잡한 행동을 포함할 때 에이전트는 우선 이를 더 작은 하위 과제로 분해하며, 분해 결과는 이후 인간 주석자가 검증·수정**한다. Gur et al. [50]은 WebAgent라는 LLM 에이전트를 소개한다. WebAgent는 지시를 표준화된 하위 지시로 분해하고 미리 계획할 수 있으므로 복잡한 과제를 더 잘 이해·실행한다. 예를 들어 복잡한 웹 조작 과제에서 먼저 실행할 주요 단계를 식별한 뒤 순서대로 수행할 수 있다.

SteP [124]는 서로 다른 행동을 더 잘 조정하고 복잡한 과제를 완수하기 위한 정책 스택을 제안한다. 과제를 여러 정책 계층으로 분해하면 각 정책은 과제의 특정 측면에 집중하여 실행 효율과 정확도를 높일 수 있다. 예를 들어 웹 과제에서는 한 정책이 페이지 탐색을, 다른 정책이 양식 채우기를 맡을 수 있다. 이 정책들은 함께 정책 스택을 이루어 전체 과제를 협력해 완료한다. Koh et al. [69]은 에이전트가 현재 상태에 따라 취할 행동을 결정하려고 트리 탐색을 수행하는 추론 시점 탐색 알고리즘을 제안한다. 이 방법은 LLM 에이전트가 상호작용적 웹 환경에서 다단계 계획을 더 잘 수행하게 한다. Knowagent [190]는 계획 단계에서 행동 경로를 안내하기 위해 행동 지식 베이스와 지식 주도 자기학습 접근을 사용한다. 행동 지식 베이스는 에이전트에 풍부한 행동 지식을 제공하여 계획 중 더 합리적인 행동 선택을 가능하게 하며, 지식 주도 자기학습은 계획 전략을 계속 학습·정제하여 전체 계획 성능을 높인다. Xie et al. [153]은 여행 계획처럼 다단계 문제를 해결할 때 LLM 에이전트를 돕는 계획 능력을 개선하기 위해 인간과 유사한 추론 프레임워크를 소개한다. Agent Q [100]는 유도 몬테카를로 트리 탐색(MCTS)과 반복 미세조정을 통합한다. 이를 통해 LLM 에이전트는 성공·실패한 모든 궤적에서 효과적으로 학습하여 복잡한 다단계 추론 과제의 일반화 능력을 높인다.

전반적으로 LLM 에이전트의 과제 분해 능력은 사용자가 복잡한 검색 과제에서 정보를 얻는 효율을 크게 높인다. 기존 접근 일부는 행동 공간을 미리 정의하고 검색 진행을 통해 다음 이동을 결정한다. 이러한 접근은 강한 제어력을 제공하지만 특정 문제 해결에 제한된다. 대조적으로 다른 접근은 모델의 자율 계획을 허용해 더 큰 유연성을 제공하지만, 분해 결과가 잘못될 수도 있다.

#### 4.2.3 질의 재작성기

전통적 검색 시나리오에서는 사용자가 검색어를 직접 정해야 하고, 검색에 반드시 포함하거나 제외할 키워드를 강조하려면 복잡한 구문도 익혀야 한다. 또 이러한 질의는 길이와 문맥이 대개 제한된다. 이 제약은 사용자가 실제 의도를 충분히 표현하지 못하게 한다. 그러나 LLM 에이전트로 이런 장애를 해결할 수 있다. LLM 에이전트는 사용자가 의도를 충분히 표현하도록 더 긴 문맥을 입력하게 하고, 스스로 더 효과적인 질의를 구성하여 검색 효율을 높인다.

CoSearchAgent [46]는 LLM으로 구동되는 경량 협업 검색 에이전트로, 인스턴트 메시지 플랫폼 Slack의 검색 플러그인 역할을 한다. 이 에이전트는 사용자 간 대화를 바탕으로 사용자 검색 의도를 자율적으로 추출해 질의로 만들고 검색 엔진을 호출하여 결과를 반환한다. 전 과정에서 사용자가 명시적으로 질의를 입력할 필요가 없으므로 대화 경험을 방해하지 않는다. Joko et al. [66]은 개인화 대화를 수집하는 LAPS(LLM-Augmented Personalized Self-Dialogue) 방식을 제안했다. 이 대화는 선호 추출과 개인화 응답 생성을 학습하는 데 쓸 수 있다. 대화 데이터가 늘어날수록 LLM 에이전트는 사용자의 여러 선호를 점차 학습한다. 예를 들어 채식 사용자가 조리법을 물으면 에이전트는 채식 요구를 고려하여 일반 조리법이 아니라 채식 관련 조리법을 직접 검색할 수 있다.

**Aliannejadi et al. [5]은 사용자 과거 상호작용과 현재 문맥의 활용법에 관한 대회를 조직하고, 다중 턴 검색-후-생성(R→G)과 생성-검색-후-생성(G→R→G)이라는 두 주요 파이프라인을 관찰**했다. 여기서 ‘G’에는 대화형 질의 확장과 대화형 재작성이 포함된다. Jain et al. [61]은 검색 증강 생성(RAG)을 이용해 LLM 에이전트가 추가 정보로 사용자 질의를 풍부하게 하는 접근을 제안한다. 구체적으로 에이전트는 RAG를 통해 GitHub 저장소에서 얻은 관련 세부 사항으로 사용자 질의를 보강한다.

요약하면 LLM 에이전트는 사용자가 검색 시스템을 활용하는 능력을 크게 높일 수 있다. 사용자가 검색 구문을 배울 필요를 없애고 검색 질의를 명시적으로 작성할 필요도 없애며, 과거 상호작용이나 외부 데이터를 바탕으로 정보를 보충하여 검색 정확도까지 개선할 수 있다.

#### 4.2.4 행동 실행기

검색 과정에는 흔히 수많은 도구 사용이 포함된다. 예를 들어 여행 계획에서는 지리적 위치, 호텔, 항공편, 날씨처럼 여러 종류의 정보를 모아야 한다. 특별히 설계된 LLM 에이전트는 적절한 도구를 신중하게 고르고 사용자를 대신해 행동을 실행하는 법을 학습할 수 있다.

AVATAR [150]는 외부 도구와 지식을 사용해 복잡한 과제를 완수할 때 LLM 에이전트 성능을 최적화하는 새로운 자동 프레임워크다. 행위자 LLM과 비교자 LLM으로 구성된다. 최적화 중 행위자는 제공된 도구를 이용해 질의에 답하는 행동을 생성한다. 비교자는 성능이 좋은 양성 질의와 성능이 나쁜 음성 질의 집합을 평가하여, 행위자에게 더 효과적인 검색 전략과 도구 사용법을 가르친다. EASYTOOL [162]은 여러 출처의 방대한 도구 문서에서 핵심 정보를 추출하고 `tool instructions`라는 통합 인터페이스를 세심하게 설계한다. 이 인터페이스는 LLM 기반 에이전트에 표준화된 도구 설명과 기능을 제공한다. 따라서 LLM이 도구 기능을 이해할 때의 인지 부하를 줄이고 도구 사용의 효율·정확도를 높인다.

CodeAct [136]는 통합된 Python 인터프리터와 함께 실행 가능한 Python 코드로 LLM 에이전트의 행동을 하나의 통합 행동 공간으로 합칠 것을 제안한다. 다중 턴 상호작용에서 CodeAct는 코드 행동을 실행하고, 새 관찰을 바탕으로 이전 행동을 동적으로 수정하거나 새 행동을 만들 수 있다. CodeNav [49]는 도구 사용 LLM 에이전트가 대개 관련 도구를 모두 LLM 문맥에 수동 등록해야 하며, 이는 복잡한 실제 코드베이스에서 한계가 된다고 지적한다. CodeNav는 대상 코드베이스 내부의 코드 조각을 자동 인덱싱·검색하여 수동 도구 등록을 없앤다. 관련 코드 스니펫을 찾아 포함하고 반복적으로 해결책을 개발할 수 있다. 전통적인 도구 사용 LLM 에이전트보다 유연하고 효율적이며, 서로 다른 코드베이스 구조와 요구사항에 적응할 수 있다.

요약하면 최근 연구는 두 핵심 영역에 집중한다. 첫째는 코드 실행·웹 검색처럼 더 넓은 범위의 도구를 LLM 에이전트에 갖추게 하는 방법이며, 둘째는 여러 선택지 가운데 가장 알맞은 도구를 LLM 에이전트가 더 잘 선택하게 하는 방법이다.

#### 4.2.5 결과 종합기

전통적 검색 과정에서는 검색 엔진이 결과를 반환한 뒤 사용자가 각 문서를 개별 검토하고 관련성을 판단하며 결론을 스스로 종합해야 한다. 그러나 이 노동집약적 과정은 LLM 에이전트로 완전히 대체할 수 있고, 검색 효율과 사용자 경험을 크게 높일 수 있다.

**PersonaRAG [165]는 실제 사용자 선호에 따라 검색과 생성을 선택하도록 사용자 중심 에이전트를 포함한 혁신적 프레임워크다. 검색, 사용자 상호작용 분석, 인지 동적 적응이라는 세 단계로 작동한다.** PersonaRAG는 여러 질의응답 데이터셋에서 기준 모델을 능가하며, 사용자 요구를 더 잘 충족하는 개인화 답변을 제공한다. ChatCite [77]는 비교 문헌 요약을 위해 인간 워크플로의 안내를 받는 LLM 에이전트다. 에이전트는 인간 워크플로를 모사해 관련 문헌에서 핵심 요소를 뽑고 성찰적·점진적 메커니즘으로 요약을 생성한다. 이 접근은 ChatCite가 문헌 내용을 더 깊이 이해하고 더 표적화되고 비교 가능한 요약을 만들게 한다. PaSa [53]는 복잡한 학술 검색 과제를 다루기 위해 Crawler·Selector 에이전트로 이루어진 계층적 아키텍처를 도입한다. Crawler는 도구 호출로 검색 질의를 동적으로 생성하고 인용 네트워크를 확장하며, Selector는 세분화된 점수로 논문 관련성을 평가한다. 이 과정을 최적화하려고 긴 지평 검색 과제의 희소 보상을 다루는 새 대화형 PPO 알고리즘을 개발했다.
+
결론적으로 대형 모델 에이전트는 여러 관점에서 검색 결과를 요약하도록 도울 수 있다. 한편으로 개인화 사용자 정보를 고려해 사용자와 관련된 콘텐츠를 필터링·강조할 수 있고, 다른 한편으로 인간 전문가를 모사하거나 전문 선택자를 쓰는 등 더 나은 정보 필터링 메커니즘을 갖출 수 있다.

#### 4.2.6 사용자 시뮬레이터

검색 효과 평가는 늘 도전 과제였다. 기존 해법은 대개 A/B 테스트를 수행하고 사용자 클릭률·체류 시간처럼 A/B 그룹 사이 지표 차이를 수집하여 알고리즘 성능을 측정한다. 그러나 이러한 통계적 측정은 사용자 만족도를 직접 반영하지 못하며, 테스트 전략이 좋지 않을 때 A/B 테스트는 실제 사용자 경험을 방해할 수 있다. LLM 에이전트는 사용자 행동을 시뮬레이션하여 이 문제의 해법을 제시한다. 앞서 말했듯 독립적 추론·행동 능력으로 LLM 에이전트는 실제 사용자 데이터에서 학습하여 사용자 의사결정 과정을 모방할 수 있다. 이 때문에 클릭 같은 단순 피드백뿐 아니라 선호하거나 싫어하는 구체적 이유도 말할 수 있다.

Usimagent [169]는 LLM 기반 검색 사용자 행동 에뮬레이터다. USimAgent는 검색 과제에서 사용자 질의·클릭·중단 행동을 시뮬레이션하고 완전한 검색 세션을 생성한다. 실제 사용자 행동 데이터셋의 실증 연구에서 연구자들은 USimAgent가 질의 생성에서 기존 방법을 능가하며, 사용자 클릭·중단 행동 예측에서는 전통 방법과 유사한 성능을 보인다는 사실을 발견했다. Sekuli [115]는 대화 검색 시스템에서 사용자 시뮬레이터의 사용 사례를 탐색한다. 사용자 시뮬레이터는 다중 턴 대화에서 명료화 질문에 자동으로 답하고 시스템 검색 결과의 합리성을 평가할 수 있다. 또한 대량의 학습 데이터를 생성하여 대화 시스템 성능을 높일 수 있다. BASES [108]는 웹 검색 사용자 행동을 포괄적으로 모사하도록 설계된 LLM 에이전트 기반 혁신적 사용자 시뮬레이션 프레임워크다. 대규모로 고유 사용자 프로필을 생성하여 다양한 검색 행동을 이끌 수 있다. 특히 방대한 웹 지식에서 학습함으로써 LLM은 인간 같은 지능과 일반화 능력을 달성할 수 있다. Chen et al. [14]은 ChatShop이라는 온라인 쇼핑 과제를 제안했다. 에이전트는 쇼핑객과 상호작용하면서 요구·선호를 점차 이해해야 한다. 저자들은 LLM 에이전트가 모사한 쇼핑객으로 에이전트 능력을 시험했고, 시뮬레이션 쇼핑객이 과제를 실제 인간 쇼핑객처럼 더 현실적이고 복잡하며 도전적으로 만든다는 사실을 발견했다.

전반적으로 대화 검색 시스템에서 LLM 에이전트를 사용자 시뮬레이터로 사용하는 일은 큰 가능성을 보인다. 평가 효율을 높일 뿐 아니라 이 시스템을 개선하는 데 가치 있는 통찰을 제공한다. 미래 연구는 대화 검색 결과 평가의 어려움을 해결하기 위해 이런 시뮬레이터의 정제와 응용을 더 탐구할 수 있다.

### 4.3 벤치마크와 데이터셋

기존 LLM 벤치마크는 주로 언어 이해·생성에 초점을 둔다. 그러나 이 데이터셋과 벤치마크만으로는 복잡하고 동적인 환경에서 에이전트의 의사결정·상호작용 능력을 포괄적으로 평가하기에 부족하다. 이 절에서는 이 영역의 연구 접근과 진전을 설명한다.

Furuta et al. [42]은 순차 과제 조합에서 언어 모델 에이전트의 한계를 드러내고, 과제 조합에 견고하고 일반화된 LLM 에이전트가 필요함을 강조하기 위해 CompWoB 벤치마크를 도입했다. CompWoB는 더 현실적인 시나리오를 반영하는 50개 새 복합 웹 자동화 과제로 된 벤치마크다. 실험 결과 기존 언어 모델 에이전트(gpt-3.5-turbo, gpt-4 등)는 기본 과제에서 평균 성공률 94.0%를 달성하지만 복합 과제에서는 24.9%로 떨어졌다. AgentBench [83]는 다양한 에이전트-과제 시나리오를 포함하고 과제 수행 데이터로 LLM 에이전트 능력을 평가한다. 이 벤치마크는 에이전트 과제에서 LLM의 강점·약점을 짚을 뿐 아니라 통일된 비교 기준도 제공한다. WebArena [186]와 MIND2WEB [28]은 URL, 열린 탭, 키보드·마우스 상호작용을 포함하여 전자상거래·사회 포럼 등 다양한 도메인의 완전한 기능을 갖춘 웹사이트로 현실적인 웹 탐색 경험을 복제하는 환경을 제공한다.

Cocktail [24]은 LLM 시대 정보 검색 모델 평가를 위한 포괄적 도구를 제공하는 벤치마크다. 인간 작성 코퍼스와 LLM 생성 코퍼스를 섞어 여러 텍스트 검색 과제·도메인을 포괄하는 16개 데이터셋으로 구성된다. 데이터셋의 다양성은 연구자가 여러 시나리오에서 정보 검색 모델 성능을 평가하게 한다. LLM 학습에 이미 포함된 데이터셋에서 비롯될 수 있는 편향을 피하기 위해 저자들은 NQ-UTD라는 새 데이터셋을 도입했다. 이 데이터셋은 최근 사건에서 유래한 질의를 특징으로 하여 평가의 공정성과 타당성을 보장한다.

전반적으로 연구자들은 IR 시나리오에서 LLM 에이전트 성능을 평가하려고 다양한 데이터셋·벤치마크를 도입했다. 텍스트 정보에 주로 초점을 두는 전통적인 LLM 평가 데이터셋과 달리, 이 데이터셋들은 실제 온라인 탐색 과제와 사용자 상호작용 행동을 자주 포함한다.

## 5. 체화된 LLM 에이전트: 차세대 추천과 검색을 향하여

LLM 에이전트는 포괄적인 능력으로 전통적인 추천·검색 모델을 강화하지만, 고정된 크기와 제한된 도메인의 데이터로 사전학습하는 것처럼 정적인 사용자-아이템 상호작용을 분석하는 데 머무르는 경우가 많다. 이 한계는 스마트 기기처럼 변화하는 환경에서 새로 나타나는 상호작용에 대응하고, 사용자·환경 양측 관점에서 능동 서비스를 제공하는 능력을 방해한다. 최근의 체화된 에이전트는 환경을 능동적으로 지각하고 상호작용함으로써 위 LLM 에이전트보다 한 걸음 나아간다. 웹 서비스에서의 자율 탐색, 온라인 콘텐츠 검색처럼 사이버 세계에서의 응용은 추천·검색 과제와 밀접하게 맞닿는 수많은 정보 검색 과정을 자연스럽게 포함한다. 이 절에서는 사이버 환경 체화 에이전트의 최신 발전, 추천·검색의 잠재 응용, 한계와 유망한 방향을 논의한다.

### 5.1 사이버 환경 체화 에이전트의 최근 발전

**체화된 에이전트.** LLM은 주목할 만한 추론 능력과 외부 도구·지식을 활용하는 역량을 가진 것으로 인정받아 왔다. 연구자들은 이를 토대로 다양한 도메인 프로필과 특정 목표에 관한 지식을 갖춘 통합 LLM 에이전트에 이 능력을 결합했다. 그러나 이런 LLM 에이전트는 인터넷 같은 실제 정보 시스템에서 미리 표본 추출한 이미지·영상·텍스트의 정적 데이터에서 수동적으로 학습한다는 의존성 때문에 여전히 제약을 받는다.

최근 연구자들은 AGI 실현의 다음 조각을 탐색하고 있다. LLM 에이전트 연구가 번성하는 가운데 강화학습(RL)과 체화 AI가 등장했다. 이에 따라 인터넷에서 수집한 고정 데이터셋 학습에 집중하는 ‘인터넷 에이전트’에서, 주변 환경과의 상호작용으로 LLM 에이전트가 학습하게 하는 ‘체화된 에이전트’로 이동하고 있다 [36]. 이름이 의미하듯 체화(embodied)는 에이전트에 물리적 기질을 부여한다. 현실 세계에서는 로봇 팔로 환경을 측정·상호작용하는 것으로, 사이버 환경에서는 정보 시스템의 ‘구동 소프트웨어’로 나타난다. 웹 에이전트는 사이버 환경 체화 에이전트의 핵심 표현 중 하나다. 이 에이전트는 GUI(그래픽 사용자 인터페이스) 기능과 상호작용해 웹사이트를 탐색하는 법을 배울 뿐 아니라 웹 시스템과 인간 사용자 양쪽의 피드백에도 효과적으로 반응해야 한다. 이런 발전에는 본질적으로 정보 검색 과제가 포함되어 에이전트가 복잡한 다단계 검색과 멀티모달 검색을 수행해야 한다. 따라서 체화된 에이전트는 추천·검색 연구의 새 시험대이자 패러다임으로 진화하고 있다.

**체화된 에이전트가 사이버 환경과 상호작용하는 방법.** 현재 웹 에이전트 구축 열기는 정적 환경과 동적 환경을 각각 고려하는 두 방향으로 나뉜다 [51, 105, 186]. 기존 접근 대부분은 에이전트 행동 궤적을 미리 수집한 인간 시연과 비교하는 정적 환경을 따른다. 예를 들어 가장 널리 쓰이는 AiTW [106] 데이터셋은 스크린샷-행동 쌍으로 된 70만 개가 넘는 순차 샘플을 포함한다. 이 경량 환경은 모델 아키텍처 설계에 더 큰 유연성을 주고 사고 연쇄(CoT) [27] 같은 더 복잡한 기술 스택 채택을 촉진한다. 하지만 이 제약된 프레임워크에서 학습된 에이전트는 과제를 완수할 때 미리 정해진 경로를 따르는 경우가 많아 실제 세계 시나리오 이해가 제한되고 새 목표에 대응하기 어렵다. 더 현실적인 평가를 위해 최근 연구는 에이전트가 실수에서 상호작용적으로 학습하고 시스템의 한계를 시험하게 하는 동적 환경을 개발했다. AndroidWorld [105]는 행동 궤적을 제한하지 않는 시뮬레이션 Android 시스템을 잘 제시한 대표 벤치마크다. 이는 실제 환경의 복잡성과 불안정성을 도입하여 에이전트의 견고성과 복잡한 과제 대응 능력에 큰 도전을 제기한다. 요약하면 두 방향 모두 광범위한 멀티모달 검색 과제를 수반하며, 추천·검색 연구의 새 교차 분야 또는 평가 환경이 될 수 있다.

**응용.** 이 접근들과 함께 체화된 에이전트는 추천·검색과 관련된 다양한 분야에서 개발되어 왔다. 웹사이트 검색에서는 외부 웹 탐색 도구를 갖춘 검색 엔진 모델을 자율 에이전트로 구현하는 데 웹 에이전트가 사용되었다 [52, 67, 68, 182]. 일반 GUI 제어에서는 잠재 상호작용 객체를 검색하기 위한 정밀한 GUI 요소 그라운딩 능력으로 GUI 에이전트가 지원되었다 [17, 54, 87, 166]. 게임 [181], 3D 환경 [57] 등의 다른 영역에서도 체화 에이전트의 응용이 활발히 성장했다.

### 5.2 체화된 에이전트를 추천과 검색에 사용할 수 있는 이유

체화된 에이전트의 광범위한 응용은 두 핵심 요인에 기반한다. 하나는 LLM에 내재된 인간 같은 언어 추론 능력이고, 다른 하나는 체화 에이전트의 상호작용 학습이다. 다음에서는 체화 에이전트가 각각 평생 학습자, 하나로 모든 것을 해결하는(One4all) 모델, 개인 비서로서 지니는 능력을 검토하여 이들이 추천·검색 과제의 실행 가능한 도구가 되는 내재적 특성을 논의한다.

- **평생 학습자:** 체화 에이전트의 핵심 강점 중 하나는 지속적이고 심지어 평생에 걸친 학습 능력이다 [132]. 고정 데이터셋에서 보통 학습되는 전통 기계학습 모델과 달리, 체화 에이전트는 환경과의 지속 상호작용을 통해 지식과 기술을 계속 확장할 수 있다. 추천 분야에서 기존 평생학습 연구 [76, 81, 161]는 장기 행동 의존성을 식별하고 새로 생기는 의도를 편입하는 데 계속 집중했지만, 이 전통적 과제별 모델은 지속적으로 파국적 망각에 시달린다. 체화 에이전트의 평생 학습자 특성은 새로운 해법이 될 수 있다.
- **One4all 모델:** 체화 에이전트의 또 다른 핵심 이점은 One4all 모델, 즉 범용 문제 해결자가 될 수 있다는 점이다. 평생 학습과 달리 one4all 모델링은 교차 도메인 과제에 집중하며, one4all 에이전트는 적응 시간, 미세조정 데이터, 성능 손실 등의 비용을 최소화하면서 보지 못한 도메인에 효율적으로 적응해야 한다. 기존 추천 연구 [18, 39, 40, 72]는 대규모 사전학습과 효율적 적응 같은 기술 덕분에 이 주제에 큰 노력을 기울였다. 그러나 여러 도메인을 매끄럽게 가로지르는 보편 표현은 아직 도달하지 못했다 [75, 122, 171]. 체화 에이전트는 새 시나리오에 빠르게 적응하여 지식 전이에 대량의 보조 정보를 제공할 수 있다.
- **개인 비서:** 체화 에이전트는 전능한 개인 비서가 될 수 있다. 평생 학습과 one4all 모델로서 유연하다는 특징은, 시공간 차원에서 빠르게 바뀌는 개인화 요구를 지각하는 유능한 비서로 체화 에이전트를 만들 수 있다. 추천·검색 과제에서는 잘 학습된 모델을 클라우드-엣지 개인 서비스로 압축할 가능성이 학계·산업계 모두에서 점차 관심사가 된다. 기존 연구 [104, 140, 159, 163]는 프라이버시 보존·사이버 보안 접근에서 경량 온디바이스 추천 시스템과 검색 도구를 달성하는 경로를 탐구했으며, 체화 에이전트는 다음 세대 해법이 될 수 있다.

**추천과 검색을 위한 체화 에이전트 설계.** 사이버 환경의 기존 체화 에이전트는 주로 GUI와의 상호작용에 초점을 두었다. 이 에이전트는 웹사이트, 데스크톱, 스마트폰 등 광범위한 정보 시스템의 GUI 조작과 과제 해결에 집중하는데, 이는 추천·검색 과제의 전형적 시나리오다. 이 밀접한 관계는 차세대 추천·검색을 위한 혁신적 접근과 해법에 영감을 줄 수 있다. WorkArena [35]는 웹 에이전트의 개발·평가를 위해 채팅 기반 에이전트-사용자 상호작용을 지원하는 최초 환경을 도입한다. 실제 인간 사용자는 채팅 인터페이스로 웹 에이전트와 메시지를 주고받는다. 이는 에이전트에 특정 답변을 기대하는 정보 검색 과제뿐 아니라, 시간이 지나면서 사용자 지시가 바뀌는 더 실제적인 과제도 가능하게 한다. 에이전트가 정보 검색 과제를 완료하고 구체적 행동·계획을 출력해야 하므로, 이 발전은 추천·검색 과제에 관한 추가 연구·토론을 촉발할 수 있다.

SmartAgent [172]는 많은 실제 개인 보조 시나리오처럼 체화 인지와 아이템 추천이 얽혀 있는 체화 개인화 학습이라는 새 과제를 정의한다. 이를 해결하기 위해 기본 GUI 탐색에서 명시적·암묵적 사용자 요구로 이어지는 점진적 사고 아래 사용자 피드백을 체화 에이전트 행동과 정렬하는 Chain-of-User-Thought(COUT)라는 새 추론 패러다임을 제안한다. COUT 패러다임을 이용해 SmartAgent는 다양한 체화 개인화 환경 범위를 처음 지원하는 새 데이터셋 SmartSpot과 함께, 최초의 전 단계 체화 개인화 능력을 보인다.

요약하면 체화 에이전트와 추천·검색 시스템의 결합은 더 개인화된 서비스를 제공하는 지능 시스템을 만들 수 있을 뿐 아니라 진정한 생체모방 개인 비서를 실현할 수도 있다. 이는 차세대 추천·검색 연구에서 잠재적으로 중요한 방향이다.

### 5.3 한계와 유망한 방향

**한계.** 체화된 에이전트는 추천·검색 분야에서 가능성을 보였지만, 몇 가지 핵심 한계도 맞닥뜨린다. 주요 과제 하나는 현재 에이전트의 일반화 능력이 제한적이라는 점이다. 기존 에이전트 대부분은 주로 정적 환경용으로 설계되어 동적인 실제 세계 시나리오에서 최적 이하의 성능을 낸다. 또한 이런 정적 환경은 보통 특정 시스템의 일면적 기능을 나타내므로, 다양한 상황에서 일반 체화 에이전트를 학습하는 일을 더 어렵게 한다. 이는 현재 체화 에이전트가 복잡한 시스템에 포함된 정보 검색 과제를 효과적으로 다룰 준비가 아직 되지 않았다는 두 번째 문제로 이어진다. 주된 이유는 에이전트가 시스템 기능 학습에 머물러 환경을 제한적으로 이해하기 때문이다. 현실 응용 시나리오는 흔히 학습 샘플을 벗어나는 비표준 경로로 표현되는 개인화 요구를 포함한다. 목표 완수 지향 체화 에이전트는 그 기저의 개인화 요구를 해결하기 어려워 사용자 참여·고착도가 낮아질 수 있다. 마지막으로 완전히 해결되지 않은 다른 중요한 기술 병목도 있다. 예를 들어 스마트폰에서 고급 교차 앱 조작을 실행하거나 데스크톱 환경에서 다중 웹페이지 과제를 처리하는 일은 여전히 어렵다.

**유망한 방향.** 이 한계들은 새 연구 방향도 촉발한다. 하나는 체화 에이전트의 one-for-all 능력을 전이 가능한 추천 또는 검색에 활용하는 것이다. 현재 대규모 사전학습 추천 모델을 새 시나리오로 전이하려면 비용이 매우 높다. 격차가 비교적 큰 새 시나리오에서는 현재 사전학습·파라미터 효율적 미세조정(PEFT) 패러다임으로 더 나은 도메인 적응을 이루기 어렵다. 체화 에이전트의 환경 동적 변화 이해 능력이 이를 도울 수 있다. 또 다른 유망한 방향은 온디바이스 추천을 위한 경량 체화 에이전트다. LLM은 모바일 기기에 배포하기에 자원 요구가 너무 큰 경우가 많아 개인화 서비스 구현을 방해한다. 더 작은 설치 공간을 지닌 체화 에이전트는 이 문제의 해법이 될 수 있다. 또한 최종 사용자 기기의 제로샷 서비스 수요는 체화 에이전트 능력에 새 요구를 제시하며 더 많은 연구를 이끌 수 있다. 마지막으로 체화 에이전트가 개인 환경의 추천·검색 영역으로 LLM 능력을 확장함에 따라 프라이버시 보존 문제는 더 중요해진다. 지능 서비스를 제공하면서 사용자 행동 모델링과 개인 프라이버시 보호를 균형 있게 맞추는 일은 중요하고 시급한 문제가 될 것이다.

## 6. 미해결 문제와 미래 방향

LLM 에이전트가 IR에 유망한 발전을 가져올 큰 잠재력을 보였지만, 해결할 과제와 탐구할 방향은 여전히 많다. 이 절에서는 이 주제를 논의한다.

**환각.** LLM의 환각은 LLM이 생성한 내용이 사실과 일치하지 않거나 검증할 수 없는 상황을 뜻한다. IR 영역의 LLM 에이전트에서 환각은 잘못된 정보 검색으로 이어져 사용자 경험을 떨어뜨릴 수 있다. 환각은 사실성 환각과 충실성 환각으로 나눌 수 있다 [58]. 전자는 LLM 생성 내용과 실제 세계의 검증 가능한 사실 사이의 불일치이고, 후자는 모델 생성 내용과 사용자 지시 사이의 불일치다. 연구자들은 이 두 환각을 완화하려는 많은 방법을 제안했다. 사실성 환각에는 RAG [45, 103, 156], CoT [144], 일관성 강화 [93, 120, 138] 같은 해법이 LLM이 주어진 출처에서 데이터를 얻도록 제약할 수 있다. 명령 유형 환각에는 프롬프트 공학, RLHF 및 기타 정렬 기술 [99, 117, 143]이 실행의 일관성을 강화할 수 있다.

**편향.** 편향은 IR 분야의 고전적 문제다. 보통 부적절한 데이터 수집 또는 학습 방법에서 생기며, 모델 결과와 실제 데이터 사이에 큰 차이를 낳아 정보 검색 정확도를 떨어뜨린다. LLM 능력은 학습 데이터에 크게 제약되므로 편향 문제에 더 쉽게 마주한다. 연구 [25, 26, 86, 184]는 LLM이 성차별 [31], 정치적 극단주의 [33], 반향실 [118] 등 다양한 편향을 유발할 수 있음을 나타낸다. Dai et al. [26]은 LLM 기반 검색기가 인간 작성 텍스트보다 LLM 생성 콘텐츠에 우선순위를 두는 경향을 발견하고, 이를 완화하는 편향 지향 손실을 도입했다.

**배포 비용.** LLM 에이전트는 보통 여러 LLM 모듈로 구성되어 일반 LLM 응용보다 호출 수와 모델 파라미터가 더 많다. 따라서 LLM 에이전트 배포에는 상당한 자원이 필요하고 추론 지연이 길어져 최종 기기의 하드웨어 요구가 높아지며 사용자 경험에 영향을 줄 수 있다. 연구자들은 이 문제에 많은 노력을 기울였다. Wilkins et al. [146]은 비용 기반 스케줄링 프레임워크를 제안해 LLM 효율을 최적화했고, Avatar [149]와 QueryAgent [59]는 도구 또는 환경 피드백으로 추론 시간을 줄인다.

**멀티모달 에이전트.** 멀티모달 LLM 에이전트는 이미지·텍스트처럼 서로 다른 양식의 데이터를 통합하여 사용자 질의를 더 포괄적으로 이해할 수 있다. 예를 들어 사용자는 상품을 질의할 때 텍스트 설명과 상품 이미지를 함께 제공할 수 있다. 멀티모달 LLM 에이전트는 텍스트·이미지 정보를 동시에 분석하고 상품 특성을 더 잘 이해해 더 정확한 검색 결과를 제공한다 [154, 175]. 최근 많은 연구는 웹페이지 [41, 183]와 모바일 기기 [92, 133]에서 LLM 에이전트 조작 능력을 높이는 데 멀티모달 능력을 활용하는 법을 탐색하기 시작했다. 이 연구들은 보통 시각 지각 능력으로 모바일 응용의 시각·텍스트 요소를 정확히 식별한다.

**도메인 특화 에이전트.** 상당한 도메인 지식이 필요한 전문 영역에서 일반 LLM 에이전트는 상식·일반 데이터 출처에 의존하기 때문에 성능이 낮은 경우가 많다. 그러나 이 전문 도메인의 데이터는 비교적 희소하여 LLM을 완전히 학습하기에 충분하지 않다. 그러므로 일반 LLM 에이전트를 도메인 특화 LLM 에이전트로 효율적·경제적으로 전환하는 일은 미래 연구의 핵심 방향이다. 현재 관련 연구는 임상 [65, 74, 111, 130, 158], 법률 [73, 126]처럼 비교적 틈새이지만 인기 있는 범주에 이미 적용되었다. 미래에는 LLM 에이전트가 희소 데이터 활용 능력을 점차 높이면서 심리 상담, 구직 같은 틈새 영역을 개선할 기회가 생길 수 있다.

**다중 에이전트 상호작용.** 다중 에이전트 시스템에서 개별 에이전트는 정보 공유와 협업을 통해 복잡한 문제를 풀 수 있다. 서로 다른 에이전트는 각기 다른 지식·기술을 가질 수 있고, 협력하면 각자의 강점을 활용하여 전체 정보 검색 성능을 높일 수 있다 [20, 147]. 최근 연구 [95, 96]는 여러 LLM 에이전트 사이의 상호작용·진화 과정을 탐색했고, 여러 다중 에이전트 프레임워크 [15, 101, 128]가 제안되었다. Infogent [107]는 웹에서 정보를 모으기 위해 다중 에이전트 시스템으로 인간 인지를 시뮬레이션했으며, Chateval [12]과 MAD [80]은 다중 에이전트 토론으로 에이전트 생성 품질을 높인다.

**개인화.** 서로 다른 사용자는 정보 검색을 수행할 때 흔히 다른 요구·선호를 보인다. 예를 들어 ‘Apple’이라는 검색어는 기술 투자자에게 Apple Inc.를 뜻할 수 있지만 다른 이에게는 과일을 뜻할 수 있다. LLM 에이전트의 메모리 모듈과 긴 문맥 처리 능력을 활용하면 개인별 맞춤 정보 검색을 달성할 수 있다 [78]. 한 접근은 사용자 상호작용 이력을 문맥으로 취급해 모델에 입력하는 것이다 [4, 89, 110]. Mo et al. [89]은 다중 턴 상호작용을 통해 사용자 요구를 충족하려고 LLM 에이전트에 대화·개인화 요소를 결합한다. 저자들은 개인 텍스트 지식 베이스(PTKB)가 대화형 정보 검색을 효과적으로 강화하여, 검색 결과가 사용자 배경에 더 밀접하게 맞게 한다고 보인다.

## 7. 결론

이 논문은 추천·검색 시스템에서 LLM 에이전트의 고도화된 응용을 검토하는 선구적 단계를 밟는다. 먼저 추천·검색 과제와 LLM 에이전트 개념을 간략히 소개하여, 입문자에게 기초 개요와 핵심 배경지식을 제공한다. 이어 LLM 에이전트의 내재적 특성을 설명하고, 이들이 추천·검색에 사용될 수 있는 이유를 보여 주는 세 구체적 측면을 강조한다. 또한 각 과제에 LLM 에이전트를 적용하는 방법을 자세히 소개한다. 각 단계에서 주요 기술과 역할을 분류하는 상세 분류 체계를 제공하여 기존 출판물 사이의 연결을 이끌어 낸다. 그 밖에 두 과제에 체화 에이전트를 적용할 잠재력을 폭넓게 논의하고, 그 고도화된 발전의 근거를 깊이 살핀다. 마지막으로 이 분야의 여러 과제와 유망한 방향을 정리하며, 이는 잠재적 미래 방향을 안내할 것으로 기대된다.
