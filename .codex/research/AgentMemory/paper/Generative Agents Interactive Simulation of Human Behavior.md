# Generative Agents Interactive Simulation of Human Behavior- 메모



- 기억 스트림 : 
  - 자연어 설명, 생성 시각, 마지막 접근 시각을 가진 기억 객체의 목록
  - 관련성, 최신성, 중요도를 결합 > 현재 행동에 필요한 기록을 고른다.
  - 관찰
    -  카페 직원 Isabella에게는 “Isabella가 페이스트리를 진열한다”, “Maria가 커피를 마시며 화학 시험을 공부한다”, “Isabella와 Maria가 카페 파티를 논의한다”, “냉장고가 비었다” 같은 관찰
    - chat portal의 경우 researcher가 해당 논문을 찾아서 읽었을 경우. 즉 사실
  - 검색
    - **최신성(recency):** 최근 접근한 기억에 높은 점수를 준다. 마지막 검색 이후 샌드박스 게임 시간에 대한 지수 감쇠를 쓰며, 감쇠 계수는 `0.995`다.
    - **중요도(importance):** 일상 기억과 핵심 기억을 구별한다. 방에서 아침을 먹는 일은 낮고, 연인과의 이별은 높다. 언어 모델에 1(양치·침대 정리처럼 평범함)부터 10(이별·대학 합격처럼 매우 가슴 아픔)까지 점수를 직접 매기게 한다. “방 청소”에는 2, “좋아하는 사람에게 데이트 신청”에는 8이 나온다.
    - **관련성(relevance):** 현재 상황과 관련한 기억에 높은 점수를 준다. 화학 시험 공부를 논의하는 상황이라면 아침 식사 기억은 낮고, 교사·학업 기억은 높다. 각 기억의 텍스트를 임베딩하고 쿼리 기억과의 코사인 유사도로 계산한다.
      - score = αimportance × importance + αrelevance × relevance + αrecency × recency
      - 세 점수는 min-max 스케일링으로 `[0, 1]`에 정규화하고, 다음 가중합으로 순위를 매긴다.
- 성찰 : 
  - 기억이 지날수록 높은 수주의 추론으로 종합 > 타인에 관한 결론은 내림
  - 원시 관찰만 가진 에이전트는 일반화·추론에 약하다
  - 하루에 두번 중요도(importance) 합이 임계값(150)을 넘게 되면 성찰을 생성 함
  - 기억이므로 검색할 때 관찰과 함께 포함
    - 방법
      - 최근 기록 100개 > 주제에 관해 답할 수 있는 상위 질문 3가지
      - 각 질문을 검색 쿼리로 사용해서 관련된 기억을 모으고 통찰
      - 문장과 인용 기억 객체 포인터? 를 성찰로 저장
- 계획
  - 현재 환경 + 결론 >> 상위 실행 계획으로 변경
  - 행동 순서 전체가 일관되려면 더 긴 시간 범위의 계획이 필요 함
  - 계획 : 위치, 시작 시간, 기간을 포함하는 미래 행동 순서
  - 계획은 하향식으로 생성
    - 이름, 성격, 최근 경험 요약 + 전날 요약 >> 큰 의제 5~8개 덩어리로 만듦
    - 큰 덩어리의 시간을 다시 쪼개서 세부 계획을 세운다.
    - 본 논문에서는 5~15분 단위로 재귀하여 분해하고, 계획을 세운다.
  - 계획은 변경될 수 있다. 
    - 이것은 관찰된 부분이 트리거이며, 해당 트리거로 장기기억을 뽑았을 때 나오는 메모리를 통해서 계획이 변경될 수 있다.



### 그럼 평가를 어떻게 하지 ?

> 이 부분은 본 논문에서 나온 평가이다. 하지만 실제 Chat Portal Agent 들은 이런 시뮬레이션 평가가 가능할지는 다시 확인이 필요할거 같아. RAG 관련된 평가를 진행해야할까.
>
> 하지만 해당 개념을 차용할 순 있을듯하다. 

- **자기 지식:** “자기소개를 해 주세요”, “일반적인 주중 일정을 큰 틀에서 설명해 주세요”처럼 핵심 특성을 유지해야 하는 질문
- **기억:** “`[이름]`은 누구인가?”, “누가 시장 선거에 출마하는가?”처럼 특정 사건·대화를 검색해야 하는 질문
- **계획:** “내일 오전 10시에는 무엇을 할 예정인가?”처럼 장기 계획을 검색해야 하는 질문
- **반응:** “아침 식사가 타고 있다면 무엇을 하겠는가?”처럼 가상 상황에 그럴듯하게 반응해야 하는 질문
- **성찰:** “최근 만난 사람 중 한 명과 시간을 보낸다면 누구이며 왜인가?”처럼 상위 추론으로 얻은 타인·자기 이해를 써야 하는 질문



결과

- 완전 기억 모듈이 넓ㅇ은 맥락에서 과거 경험을 회상하고 자기 지식과 일관된 답을 할 수 있었음
- 하지만 올바른 기억 사례를 검색하지 못하기도 함.
  - 즉 검색을 잘 찾는 방법이 필요
- **허구를 단정하는 일은 드물지만 지식을 부연하는 환각 존재**
- 3가지 불규칙 행동
  - 기억 집합과 에이전트가 아는 장소가 계속 커지면 관련 정보를 검색할 뿐 아니라 행동할 적절한 공간을 정하기도 어려워진다
  - 연어로 전달하기 어려운 장소의 물리적 규범이 에이전트에게 전달되지 않아 올바른 행동 분류가 틀렸다
    - 즉 명확한 조건과 지시가 필요하다는 뜻이며, 단어 선택 또한 명확행야한다는 것을 보여주는 것 같음
