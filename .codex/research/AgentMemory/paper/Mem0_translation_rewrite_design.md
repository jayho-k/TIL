# Mem0 논문 번역 재작성 설계

> 대상: `Mem0_Building_Production_Ready_AI_Agents_with_Scalable_Long_Term_Memory_ko_translation.md`  
> 원문: `2504.19413v1.pdf` (arXiv:2504.19413v1, 2025-04-28)

## 목적

PDF 텍스트 추출 과정에서 생긴 두 단 조판 혼입, 페이지 머리글, 문장 분절, 표 붕괴를 제거한다. 원문의 정보 범위를 줄이지 않고 읽을 수 있는 한국어 Markdown 번역본으로 재작성한다.

## 범위와 보존 기준

- 초록, 1~6절, 참고문헌, 부록 A~C를 모두 포함한다.
- 그림 1~4와 표 1~2의 캡션·주석·수치·각주를 유지한다.
- 수식, 기호, 알고리즘, 프롬프트, URL, 모델명·데이터셋명은 원문 표기를 우선 보존한다.
- 본문과 캡션은 문장 단위로 번역하고, PDF 쪽수·머리글·두 단 순서에서 비롯된 잡음은 포함하지 않는다.

## 문서 레이아웃

- 원문 계층을 Markdown 제목으로 대응한다 (`##` 절, `###` 하위 절).
- 그림 설명은 인용문, 표는 Markdown 표 또는 읽기 쉬운 행 단위 표기로 정리한다.
- 부록의 LLM 프롬프트와 알고리즘은 코드 블록으로 분리한다. 프롬프트 내부의 `#`는 Markdown 제목이 아니라 코드 내용으로 취급한다.
- 해석이나 비평은 이 번역본에 넣지 않고 기존 분석 노트에 남긴다.

## 검증 기준

원문과 제목 구조를 대조하고, 4개 그림·2개 표·3개 부록과 모든 본문 절이 존재하는지 확인한다. 페이지 머리글, 단독 괄호, 깨진 줄바꿈 잔재가 없는지도 검사한다.
