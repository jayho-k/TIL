# 논문 번역본 가독성 재편집 설계

작성일: 2026-07-27  
대상: Generative Agents, Mem0, MemGPT의 한국어 완역 Markdown 3개

## 목표

PDF에서 줄 단위로 추출·번역된 초안을, 분석 노트와 같은 읽기 흐름의 Markdown으로 재구성한다. 원문 내용은 생략하지 않는다.

## 편집 원칙

1. 제목, 저자, 초록, 본문 절, 그림·표, 각주, 참고문헌, 부록을 Markdown 계층으로 분리한다.
2. PDF의 행바꿈, 2단 레이아웃, 페이지 머리말·꼬리말, 단어 중간 하이픈 분할을 제거하고 문단 단위로 복원한다.
3. 그림·표 캡션은 본문과 분리하고, 수식·알고리즘·프롬프트는 코드 또는 수식 블록으로 표시한다.
4. 문단의 뜻을 바꾸지 않는 범위에서 기계번역의 어색한 용어와 문장 연결을 고친다.
5. 원문에 있는 저작권 안내, 각주, 참고문헌, 부록도 유지한다. 참고문헌의 저자·제목·출판 정보는 식별성을 위해 원문 표기를 보존할 수 있다.

## 파일별 처리

| 논문 | 편집 대상 |
| --- | --- |
| Generative Agents | memory stream, retrieval 수식, reflection·planning 절, 통제/종단간 평가, 부록 인터뷰 질문 |
| Mem0 | extraction/update, Mem0g graph, LOCOMO 표, 성능·latency·token 결과, 프롬프트/알고리즘 부록 |
| MemGPT | memory tier, queue/function/event loop, 대화·문서 평가, 프롬프트 부록 |

## 검증 기준

- 원문 PDF와 대조해 쪽수, 주요 최상위 섹션, 부록, 그림/표 캡션 수를 확인한다.
- 완역본에 끊긴 단어, 페이지 머리말, 임시 처리 표식이 남지 않았는지 검사한다.
- 각 분석 노트가 새 번역본 링크를 계속 가리키는지 확인한다.

## 비범위

- 논문의 내용 축약 또는 분석 노트 내용 변경
- 원본 PDF 이름 변경
- 원문의 표·그림을 이미지로 재제작
