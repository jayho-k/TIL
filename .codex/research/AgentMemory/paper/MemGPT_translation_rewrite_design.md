# MemGPT 번역문 전면 재작성 설계

## 목적

`MemGPT_Towards_LLMs_as_Operating_Systems_ko_translation.md`를 영어 원문과 단락 단위로 다시 대조해, 텍스트 추출 오류와 부정확한 기계 번역을 제거한다. 원문의 정보량과 순서는 보존한다.

## 범위

- 제목, 저자, 초록, 본문 1~5장, 참고문헌, 부록을 모두 포함한다.
- 그림·표 캡션, 인라인 인용, 각주 성격의 설명, 코드·프롬프트·함수 호출을 누락하지 않는다.
- 코드, 함수명, 변수명, 모델명, 데이터셋명은 원문 표기를 유지한다. 주변 설명은 자연스러운 한국어로 번역한다.
- 반복되는 문장이나 프롬프트도 축약·발췌·의역하지 않는다.

## 편집 원칙

1. 원문 제목과 섹션 번호를 기준으로 Markdown 계층을 맞춘다.
2. PDF의 다단 레이아웃에서 섞인 문장 순서는 의미 단위로 복원한다.
3. 표는 Markdown 표로 옮기고, 원문의 행·열·수치·주석을 보존한다.
4. 그림은 이미지 파일이 없으므로 `> 그림 N.` 형태의 캡션과 본문 참조를 유지한다.
5. 해석·비평·현대적 보충 설명은 넣지 않는다. 이는 별도 analysis 노트의 역할이다.

## 검수 기준

- 원문의 모든 최상위·하위 섹션 및 부록 항목이 번역문에 존재한다.
- 그림/표/코드 블록/함수 호출 수와 순서를 원문과 대조한다.
- 영문이 부자연스럽게 섞인 본문, 깨진 낱말, 다단 추출 잔재가 남지 않는다.
- 인용 키와 수치·실험 결과가 원문과 일치한다.

## 제외 범위

- 논문 비평, 핵심 요약, 다른 노트로의 이관, `.codex/MAP.md` 변경은 이번 작업에 포함하지 않는다.
