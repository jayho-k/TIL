# 최소 검증 실습 — tenant·scope·lifecycle이 검색 결과를 제한하는지 확인하기

> 학습 단계: 9 / 9  
> 목적: 09 설계안의 격리·상태 전이 가설을 Qdrant 로컬 인스턴스에서 검증한다.  
> 범위 밖: 실제 embedding 품질, Hybrid 성능, PostgreSQL outbox, snapshot 복구 자동화.

## 이 실습이 증명하는 것과 증명하지 않는 것

이 실습은 사람이 만든 3차원 vector를 사용한다. 따라서 vector가 의미를 얼마나 잘 이해하는지는 증명하지 않는다. 대신 query vector가 의도적으로 특정 Point에 가깝도록 만들기 때문에, **payload filter와 lifecycle 정책이 실제 반환 결과를 제한하는지**를 명확히 볼 수 있다.

| 검증 | 기대 결과 |
| --- | --- |
| tenant 격리 | tenant-A query에서 tenant-B Point가 절대 반환되지 않음 |
| agent private | agent-A private Point가 agent-B query에 반환되지 않음 |
| shared memory | 같은 tenant의 `user_shared` Point는 허용 범위에서 반환됨 |
| lifecycle | `superseded`로 바꾼 Point는 `status=active` query에서 사라짐 |
| delete | 삭제한 Point는 API query에서 반환되지 않음 |

## 1. 준비

Docker로 Qdrant를 실행한다.

```powershell
docker run --rm -p 6333:6333 -p 6334:6334 qdrant/qdrant:latest
```

다른 PowerShell에서 Python client를 설치하고 실습을 실행한다.

```powershell
python -m pip install qdrant-client
python .codex\research\Qdrant\code\10_memory_scope_lab.py
```

이 스크립트는 로컬 Qdrant의 `agent_memory_lab` Collection만 삭제 후 다시 만든다. 운영 Collection에는 실행하지 않는다.

## 2. 코드가 만드는 Point

```text
tenant-A
├─ research-agent private Point
├─ user shared Point
└─ supersede/delete를 확인할 Point

tenant-B
└─ query vector와 매우 가깝지만 tenant-A에서는 보이면 안 되는 Point
```

`tenant-B` Point를 일부러 가장 가까운 vector로 넣는다. tenant filter가 빠지면 이 Point가 반환되어 격리 실패를 바로 확인할 수 있다.

## 3. 실행 결과 해석

성공하면 다음과 비슷한 출력이 나온다.

```text
[PASS] tenant-A search excludes tenant-B point
[PASS] agent-A private memory is not returned to agent-B
[PASS] user_shared memory is returned inside tenant-A
[PASS] superseded memory is excluded from active recall
[PASS] deleted memory is inaccessible
```

실패했다면 vector DB의 문제가 아니라 먼저 query filter 생성 경로를 의심한다. 특히 tenant filter와 `status=active`를 공통 helper로 강제했는지 확인한다.

## 4. 다음 실험

이 최소 실습을 통과한 뒤에만 실제 embedding 모델과 memory corpus로 다음을 평가한다.

- dense-only와 dense+sparse RRF의 Recall@K/NDCG@K
- threshold·Top-K·`hnsw_ef`가 latency와 recall에 미치는 영향
- candidate/active를 같은 Collection에 둘 때의 filter 비용
- Qdrant와 원장 DB의 outbox 재시도·snapshot 복구 reconcile
